# Skill Power

Skills are capabilities available to you. For every user request or task, first consider whether a relevant skill can help you complete it with higher quality.

## Usage

Skills available to you are listed under `Available Skills` in the runtime inventory. Before using one, load its content through the `skill` power's `lookup` action.

Call this power with:

```ts
skill({
  action: "lookup",
  args: {
    name: "<skill-name>",
  },
});
```

Available actions are `list` and `lookup`.

`list` returns the skills in your own skill directory by default. Pass `scope` to read other sources: `project` for the current workspace `.agents/skills`, `home` for the user directory `~/.agents/skills`, and `all` for the union of your directory, project, and home. `lookup` accepts the same `scope`.

The runtime inventory, `list`, and `lookup` all default to the same set, so the skill names shown to you are directly usable.

You cannot install or link skills. Ask the user to add a skill from the Skills page when you need one that is not listed.
