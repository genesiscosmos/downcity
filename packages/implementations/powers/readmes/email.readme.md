# Email

Email 使用 IMAP 读取邮箱、SMTP 发送纯文本邮件。支持多个邮箱账号；每次操作按需连接，无需后台监听。

在 Email 工作区添加账号，填写邮箱地址、IMAP 和 SMTP 的主机、端口、用户名及密码或授权码。连接必须使用 TLS 或 STARTTLS。保存后可测试两种协议的连接与认证；测试不会发送邮件。已配置密码不回显，编辑时留空保留；更改认证目标时需重新填写密码。

选择已启用 Email Power 的 Agent 和邮箱账号后，可以浏览文件夹、搜索关键词/发件人/主题、筛选未读邮件、读取正文并显式标记已读或未读。打开邮件不会自动标记已读。正文以有限长度纯文本显示，不加载远程图片。

附件可下载至 Email 的私有存储，单个附件最多 20 MiB。已下载附件可在本次工作区的写信或回复表单中选择；发送附件合计最多 20 MiB，不接受任意宿主路径。单封邮件读取上限为 25 MiB，正文最多展示 100,000 字符。

写信或回复后，点击“交给 Agent 审批发送”，Downcity 会打开所选 Agent 的普通会话。请在会话中核对内容并完成审批。表单提交不表示邮件已发送；SMTP 接受也不表示最终送达。发送结果不确定时，先核对邮箱，再决定是否重试。
