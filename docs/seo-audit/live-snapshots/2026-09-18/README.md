## 为什么要留原件

那一轮的审计方式写明是「线上实测，非本地产物」，而这条约束不是修辞：

- **线上与仓库不是一回事。** 当时仓库领先 `origin/main` 18 个提交，线上跑的是旧版本，
  仓库里的修复一律还没生效。要看「线上现在到底长什么样」，只能抓线上。
- **本地产物复现不出来。** 本目录三份文件与 `homepage/build/client/` 对应页**逐字节不同**，
  因为它们来自不同版本、不同构建。事后重建本地包不能还原线上响应。
- **最严重的结论靠它证明。** P0-0 的判断是「`/zh/**` 全部预渲染成英文正文」——
  `features.zh.html` 就是证据：`<html lang="zh">`、canonical 指向 `/zh/features/`，
  正文却全是英文。删掉快照，这条结论就只剩文字断言。
