# Memory Plugin

The Memory plugin manages durable facts, preferences, and experience across Sessions. Session remains the source of truth for complete conversations; MemoryPlugin does not own Session Messages.

## Memory scopes

- **User Memory** — shared across Agents for the same authenticated City user.
- **Workspace Memory** — shared across Agents using the same City Workspace.
- **Agent Memory** — private experience and long-running state for one Agent.

Core Memory enters separate system blocks. Dynamic Recall for the current request is attached only to the current Turn's User Message model-input copy and never changes the original message.

City only supplies a shared root to MemoryPlugin. Memory formation, persistence, recall, and isolation remain plugin responsibilities.
