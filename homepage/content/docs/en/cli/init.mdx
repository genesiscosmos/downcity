# Project Init

`city agent create` creates Workspace runtime and Skills directories, then stores the Agent as a global entity. It does not generate an Agent declaration file in the Workspace.

```bash
city agent create my-project
```

Generated structure:

```text
my-project/
├── .env
├── .agents/
│   └── skills/
└── .downcity/
```

The global database stores the Agent ID, model binding, startup options, and Plugin config. Project `.env` overrides platform global env and the current CLI process env.

```bash
# Allow replacing existing Agent config in the global database
city agent create my-project --force
```

After initialization, add project Skills under `.agents/skills`, inspect the generated `agent_id` with `city agent list`, then run `city agent start <agent_id>`.
