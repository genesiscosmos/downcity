# 插件

**插件（Plugin）** 是 Downcity 唯一的扩展产品单元。它既可以向 Agent 提供运行能力，也可以带上自己的宿主管理逻辑和唯一 Mainview，而不需要额外的 Extension 概念。

```text
Plugin
├── agent      可选：Agent 运行能力
├── main       可选：管理逻辑与 actions
└── renderer   可选：唯一 Mainview
```

## 插件能做什么

- 向 Agent 暴露可调用的工具
- 接入 Agent 生命周期（启动、停止、会话事件）
- 管理自己的状态、连接和后台任务
- 在自己的 Mainview 中管理 Profile 配置
- 在 Agent 进程边界内运行，不作为独立服务

Profile 只是宿主在某个 Plugin 下提供的配置隔离空间。进入 Plugin 页面后创建或选择 Profile，由 Plugin 自己的 Mainview 完成配置；Agent 只选择 Plugin 与 Profile，不保存渠道、账号或 Token。

## 内置插件

Downcity 内置了多个插件，覆盖常见的 Agent 需求：

- **Chat** — 连接聊天渠道（Telegram、飞书、QQ 等）
- **Task** — 调度和运行后台任务
- **Memory** — 持久化会话历史和上下文
- **Contact** — 管理用户联系人列表
- **Shell** — 在沙箱环境中执行本地命令
- **Schedule** — 类 Cron 的作业调度
- **Web** — 浏览网页并提取内容
- **Skill** — 组合可复用的工具链

## 编写插件

SDK 中的 Plugin 仍然是普通 TypeScript 实例，可以直接传给 Agent，不需要经过安装协议：

```ts
const agent = new Agent({
  id: "coding-pro",
  model,
  plugins: [new GithubPlugin({ token })],
});
```

需要被 CLI 或 Desktop 安装和管理时，再通过 `plugin.json` 声明可选的 `agent`、`main` 与 `renderer` 入口。
