# 插件

**插件（Plugin）** 是 Downcity 唯一的扩展产品单元。它由 City 提供和维护，可以向 Agent/Session 作用域投影运行能力，也可以带上宿主管理逻辑、Sidebar + Mainview 业务工作区和 Config。

```text
Plugin
├── main       可选：City 运行实例、生命周期、管理逻辑与 actions
└── renderer   可选：Sidebar + Mainview 和/或 Config
```

## 插件能做什么

- 向 Agent 暴露可调用的工具
- 接入 City Plugin 生命周期（start、bind、unbind、stop）
- 管理自己的状态、连接和后台任务
- 提供不依赖 Profile 的 Sidebar + Mainview 工作区，并在 Catalog 详情的独立 Config 中管理配置
- 在 City 进程边界内运行，不作为独立服务

Profile 是 City 为 Plugin 提供的配置隔离空间，与业务工作区无关。相同 `(plugin_id, profile_id)` 在一个 City 内共享实例；Agent 只声明 Plugin/Profile 绑定，不持有实例或生命周期。

## 内置插件

Downcity 内置了多个插件，覆盖常见的 Agent 需求：

- **Chat** — 连接聊天渠道（Telegram、飞书、QQ 等）
- **Task** — 调度和运行后台任务
- **Memory** — 持久化会话历史和上下文
- **Shell** — 在沙箱环境中执行本地命令
- **Schedule** — 类 Cron 的作业调度
- **Web** — 浏览网页并提取内容
- **Skill** — 组合可复用的工具链

## 编写插件

SDK 中通过 `CityPluginRegistration` 提供 Plugin，再按 ID 绑定 Agent，不需要经过安装协议：

```ts
const city = new City({ plugins: [github_registration], workspaces: [workspace] });
city.agents.add(agent, { plugins: [{ plugin_id: "github" }] });
```

需要被 CLI 或 Desktop 安装和管理时，再通过 `plugin.json` 声明统一 `main` 与可选 `renderer` 入口。
