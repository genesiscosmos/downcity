# 自定义插件

一个第三方制品只定义一个 Plugin。Plugin 的全局唯一 ID 同时是最终目录名、Agent 引用键和运行时 Registry key。

## 制品结构

```text
github-plugin/
├── downcity.plugin.json
└── dist/index.js
```

ESM 入口命名导出一个 constructor：

```ts
export const plugin = GithubPlugin;
```

## Plugin constructor

```ts
import type { JsonObject } from "@downcity/agent";

export class GithubPlugin {
  static readonly manifest = {
    name: "github",
    version: "1.0.0",
    title: "GitHub",
    description: "GitHub 集成",
    config: {
      schema: GITHUB_PROFILE_JSON_SCHEMA,
      defaults: { api_url: "https://api.github.com" },
    },
  };

  readonly name = "github";
  readonly actions = {};

  constructor({ config }: { config: JsonObject }) {
    // config 是 Agent 选择的完整 profile。
  }
}
```

实例 `name`、静态 `manifest.name`、安装 Manifest `id` 和目录名必须一致。运行时统一执行：

```ts
new GithubPlugin({ config: selected_profile });
```

账号、Token、端点等结构直接属于 profile Schema。框架不再定义 Binding、Resource、Resolver 或 Installation 持久化领域。

## 静态清单

安装阶段读取 v4 静态文件，不执行第三方代码：

```json
{
  "manifest_version": 4,
  "id": "github",
  "version": "1.0.0",
  "title": "GitHub",
  "description": "GitHub 集成",
  "entry": "dist/index.js",
  "config": {
    "schema": {
      "type": "object",
      "properties": {
        "api_url": { "type": "string", "format": "uri" },
        "token": { "type": "string", "writeOnly": true }
      },
      "additionalProperties": false
    },
    "defaults": { "api_url": "https://api.github.com" }
  }
}
```

安装后的目录是确定的：

```text
~/.downcity/plugins/github/
├── plugin.json
├── config.toml
└── artifact/
```

`config.toml` 保存命名的明文 profile，文件权限为 `0600`。CLI 与 Desktop 展示配置时会脱敏 Schema 标记为 `writeOnly` 的字段。

## 安装与配置

```bash
city plugin install ./github-plugin
city plugin config github production --interactive
city plugin enable github my-agent --profile production
city plugin update github
city plugin uninstall github
```

更新只替换 `plugin.json` 与 `artifact/`，保留 `config.toml`。新 Schema 无法校验已有 profile 时更新失败；仍被 Agent 引用的 profile 或 Plugin 不能删除。

安装过程不会执行 `npm install`、构建脚本、生命周期脚本或 Plugin 入口，并记录 Git commit 和制品 SHA-256 摘要。Plugin 入口会在 Agent 加载时执行，因此只应安装可信来源。
