# Shell

Shell 是 Workspace 能力，不是 Plugin。它持有 Sandbox Provider、当前 Workspace 的隔离 Sandbox 与可复用的 Shell Session。

## 功能

- 默认在 Workspace Sandbox 中执行命令
- 在不同 Chat Session 之间保留已安装工具和 HOME 状态
- 捕获 stdout、stderr 和退出码
- 支持超时和取消

## 安全

Shell 只有 `sandbox` 和 `host` 两个执行目标。默认使用 Sandbox，且不能看到任意宿主路径；host 执行必须提供明确原因并经过宿主审批。Sandbox 失败时不会回退到宿主执行。

## 使用场景

- 运行构建脚本
- 文件系统操作
- 查询系统状态
- 执行项目特定工具
