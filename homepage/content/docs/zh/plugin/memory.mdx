# Memory 插件

Memory 插件管理跨 Session 的长期事实、偏好和经验。Session 自己保存完整对话；MemoryPlugin 不接管 Session Messages。

## 记忆范围

- **User Memory** — 同一认证用户在 City 内跨 Agent 共享。
- **Workspace Memory** — 同一 Workspace 在 City 内跨 Agent 共享。
- **Agent Memory** — 当前 Agent 的私有经验和长期状态。

Core Memory 进入独立 system block；当前问题的 Dynamic Recall 只进入本轮 User Message 的模型输入副本，不修改原始消息。

City 只向 MemoryPlugin 提供共享根路径。Memory 的生成、持久化、召回和隔离策略都由插件内部负责。
