<!-- Desktop 面向用户的消息阅读与折叠操作说明。 -->

Agent 消息采用左右布局：左侧竖排头像与可选折叠按钮，右侧顶部信息栏显示 Agent 名称和时间，中间展示消息主体，下方展示文件改动。信息栏与主体之间保留间距。复制、引用和分支等消息操作位于全部内容下方；有文件改动时，操作栏显示在文件改动卡片之后。

有执行过程时，头像下方显示箭头折叠按钮，与头像竖向排列。按钮常显，悬停时显示浅色背景；收起时箭头朝右，展开时朝下。点击按钮可展开或收起执行过程，也可以通过键盘操作。

生成过程中，执行过程默认展开；完成后默认收起。收起时隐藏过程，最终回答保持完整可见，不再显示工具摘要折叠栏。只有执行过程而没有最终回答时，左侧箭头仍可用于重新展开。

展开与收起以按钮为滚动锚点。手动切换后，这条消息会保留你的选择。没有执行过程的消息直接展示回答，不显示折叠按钮。
