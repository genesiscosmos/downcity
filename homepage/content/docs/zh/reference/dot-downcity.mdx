# `.downcity/` 目录

`.downcity/` 是 Downcity 的本地运行数据目录，默认建议不提交到 Git。

通过 Downcity 初始化项目时，系统会自动把 `.downcity` 追加到当前项目的 `.gitignore`。

## 常见结构

```text
.downcity/
  logs/
  agents/
  chat/
  task/
  data/
  public/
  resources/
  .cache/
```

## 重点目录

### `.downcity/logs/`

每日 JSONL 日志：`<YYYY-MM-DD>.jsonl`。

### `.downcity/agents/<agent_id>/sessions/<session_id>/messages/`

会话消息事实源：`active.jsonl`、`assistant_message.json` 与按 sequence 命名的 `segments/*.jsonl`。

### Agent Memory

长期 Memory 不属于 Workspace `.downcity/` 协议。Memory 内容由当前 Agent 启用的 `MemoryProvider` 管理；内建 File Adapter 默认使用 `~/.downcity/agents/<agent_id>/memory/`，其他 Provider 可以使用数据库或远程服务。

### `.downcity/chat/`

chat 元信息与 history 事件流。`access.db` 保存当前 Agent 的 Chat Principal、Request、Allow/Deny Grant 和审计事件；`migration-backup/authorization/` 保存一次性迁移后的旧授权 JSON。

### `.downcity/channel/meta.json`

渠道目标到 `session_id` 的映射快照（由 chat plugin runtime 维护）。

### `.downcity/task/`

任务定义与每次运行产物（`run.json`、`result.md` 等）。

### Skills 目录位置

`SkillPlugin` 默认扫描 `.agents/skills`（项目级）。如果在构造函数中启用 `use: ["home"]`，也会扫描 `~/.agents/skills`（用户级）。

## 安全建议

- `.downcity/` 可能含敏感对话与执行痕迹，不建议提交到公开仓库。
- 需要排障时优先查看 `logs`、`task`、`agents` 三处。
