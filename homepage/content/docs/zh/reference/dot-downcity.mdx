# `.downcity/` 目录

`~/.downcity/` 是 Downcity 的用户级配置与运行数据目录。Downcity 不会在每个项目中创建 `.downcity/` 目录。

## 常见结构

```text
~/.downcity/
├── agents/<agent_id>/
│   ├── agent.json
│   ├── SOUL.md
│   ├── sessions/<origin_type>/<session_id>/
│   ├── archived-sessions/<origin_type>/<session_id>/
│   └── logs/
├── plugins/<plugin_id>/
│   └── config.toml
├── runtimes/city/
└── downcity.db
```

## 重点目录

### `agents/<agent_id>/logs/`

每日 JSONL 日志：`<YYYY-MM-DD>.jsonl`。

### `agents/<agent_id>/sessions/<origin_type>/<session_id>/messages/`

会话消息事实源：`active.jsonl`、`assistant_message.json` 与按 sequence 命名的 `segments/*.jsonl`。
默认来源分区是 `chat`；其他任意非空来源类型会被编码为安全的单个目录段。

### Memory

长期 Memory 不属于 Workspace `.downcity/` 协议。Agent 私有内容位于 `agents/<agent_id>/plugins/memory/`；City 共享的 User/Workspace 内容位于 `memory/`，并由 `MemoryPlugin` 按 Subject 隔离。City 只提供共享根路径，不实现 Memory 数据逻辑。

### Plugin 运行数据

Plugin 自有运行数据使用 PluginContext 提供的 Agent 级存储作用域。Plugin 定义与 profile 仍保存在 `~/.downcity/plugins/<plugin_id>/`。

### Skills 目录位置

`SkillPlugin` 默认扫描 `.agents/skills`（项目级）。如果在构造函数中启用 `use: ["home"]`，也会扫描 `~/.agents/skills`（用户级）。

## 安全建议

- `~/.downcity/` 可能包含敏感配置、对话、Token 与执行痕迹。
- 不要把该目录提交到版本库或复制到不受信任的位置。
