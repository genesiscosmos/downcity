# `.downcity/` 目录

`~/.downcity/` 是 Downcity 的用户级配置与运行数据目录。Downcity 不会在每个项目中创建 `.downcity/` 目录。

## 常见结构

```text
~/.downcity/
├── agents/<agent_id>/
│   ├── agent.json
│   ├── SOUL.md
│   └── workspaces/<workspace_id>/
│       ├── sessions/
│       ├── archived-sessions/
│       └── logs/
├── plugins/<plugin_id>/
│   └── config.toml
├── runtimes/city/
└── downcity.db
```

## 重点目录

### `agents/<agent_id>/workspaces/<workspace_id>/logs/`

每日 JSONL 日志：`<YYYY-MM-DD>.jsonl`。

### `agents/<agent_id>/workspaces/<workspace_id>/sessions/<session_id>/messages/`

会话消息事实源：`active.jsonl`、`assistant_message.json` 与按 sequence 命名的 `segments/*.jsonl`。

### Agent Memory

长期 Memory 不属于 Workspace `.downcity/` 协议。Memory 内容由当前 Agent 启用的 `MemoryProvider` 管理；内建 File Adapter 默认使用 `~/.downcity/agents/<agent_id>/memory/`，其他 Provider 可以使用数据库或远程服务。

### Plugin 运行数据

Plugin 自有运行数据使用当前 AgentWorkspace context 提供的私有存储作用域。Plugin 定义与 profile 仍保存在 `~/.downcity/plugins/<plugin_id>/`。

### Skills 目录位置

`SkillPlugin` 默认扫描 `.agents/skills`（项目级）。如果在构造函数中启用 `use: ["home"]`，也会扫描 `~/.agents/skills`（用户级）。

## 安全建议

- `~/.downcity/` 可能包含敏感配置、对话、Token 与执行痕迹。
- 不要把该目录提交到版本库或复制到不受信任的位置。
