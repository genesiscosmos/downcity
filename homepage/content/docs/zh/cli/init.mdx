# 项目初始化

`city agent create` 创建 Workspace 运行目录和 Skills 目录，并把 Agent 作为全局实体写入数据库。Workspace 中不生成 Agent 声明文件。

```bash
city agent create
```

不传路径时，交互流程可以直接使用当前目录，或者打开操作系统原生文件夹选择窗口。传入相对路径或绝对路径则直接使用该路径，不进入目录选择流程：

```bash
city agent create .
city agent create ./my-project
city agent create /absolute/path/to/my-project
```

生成结构：

```text
my-project/
├── .env
├── .agents/
│   └── skills/
└── .downcity/
```

全局数据库保存 Agent ID、模型绑定、启动参数和 Plugin 配置。项目 `.env` 会覆盖 `~/.downcity/.env` 中的 Global Env；启动进程显式环境变量拥有最高优先级。

```bash
# 允许覆盖全局数据库中的现有 Agent 配置
city agent create ./my-project --force
```

初始化后，可在 `.agents/skills` 添加项目 Skills，并通过 `city agent list` 查看生成的 `agent_id`，再运行 `city agent start <agent_id>`。
