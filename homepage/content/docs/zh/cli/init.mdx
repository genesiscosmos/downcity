# 项目初始化

`city agent create` 会独立登记 Workspace，并创建 Agent 的用户级 `agent.json` 与 `SOUL.md`。它不会在 Workspace 中生成 Agent 声明，也不会保存 Agent-Workspace 绑定。

```bash
city agent create
```

不传路径时，交互流程可以直接使用当前目录，或者打开操作系统原生文件夹选择窗口。传入相对路径或绝对路径则直接使用该路径，不进入目录选择流程：

```bash
city agent create .
city agent create ./my-project
city agent create /absolute/path/to/my-project
```

生成结构：

```text
my-project/
├── .env
├── .agents/
│   └── skills/
└── .downcity/
```

Agent 定义写入 `~/.downcity/agents/<agent_id>/agent.json`，主体指令写入同目录的 `SOUL.md`；Workspace 登记仍保存在 `downcity.db`。项目 `.env` 会覆盖 `~/.downcity/.env` 中的 Global Env；启动进程显式环境变量拥有最高优先级。

```bash
# 允许覆盖现有 Agent 文件定义
city agent create ./my-project --force
```

初始化后，可在 `.agents/skills` 添加项目 Skills，通过 `city agent list` 查看生成的 `agent_id`，直接运行 `city agent chat <agent_id>`，或执行 `city on` 启动长期 City 宿主。
