---
title: Credits Service
description: 使用永久 Primary Card 与限时 Ephemeral Card 管理用户额度。
---

`CreditsService` 只负责额度持有和消费，不负责支付订单、奖励活动规则或模型定价。

```ts
import { Federation } from "@downcity/city";
import { CreditsService } from "@downcity/services";

const federation = new Federation({ database });
const credits = new CreditsService();
federation.use(credits);
```

用户读取自己的当前 Credits 账户：

```ts
const account = await city.service("credits").get("me");
```

响应以 Card 为事实源，同时提供总可用额度：

```json
{
  "user_id": "user_123",
  "available_credits": 1200000,
  "cards": {
    "primary": {
      "kind": "primary",
      "user_id": "user_123",
      "credits": 1000000,
      "created_at": "2026-07-01T00:00:00.000Z",
      "updated_at": "2026-07-29T10:00:00.000Z"
    },
    "ephemeral": [
      {
        "kind": "ephemeral",
        "card_id": "card_welcome",
        "user_id": "user_123",
        "name": "新用户奖励",
        "credits": 200000,
        "expires_at": "2026-08-05T12:00:00.000Z",
        "source": "welcome",
        "ref": "",
        "created_at": "2026-07-29T00:00:00.000Z",
        "updated_at": "2026-07-29T00:00:00.000Z",
        "status": "active"
      }
    ]
  }
}
```

`ephemeral` 只包含当前有效且有余额的 Card，并按到期时间升序排列。已耗尽或已过期额度通过 Transaction 与 Card 流水查询。

管理端使用 `bureau.credits` typed invoker。第一版不支持匿名主体、转账、负余额、Card 延期或关闭。
