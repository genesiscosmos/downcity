---
title: Accounts、Credits 与 Payment
description: Downcity 官方身份、额度、支付和用量服务。
---

`@downcity/services` 提供四个职责独立的领域：

- `AccountsService` 拥有登录与用户身份。
- `CreditsService` 拥有 Primary / Ephemeral Cards 和账务记录。
- `PaymentService` 拥有支付订单、Checkout 与 webhook。
- `UsageService` 记录服务调用用量。

```ts
const credits = new CreditsService();
const payment = new PaymentService({
  providers: [stripePaymentProvider()],
  on_paid: async (record) => {
    await credits.topup({
      card: { kind: "primary", user_id: record.user_id },
      credits: record.credits,
      source: "payment",
      ref: record.payment_id,
      idempotency_key: `payment:${record.payment_id}`,
    });
  },
});

federation.use(new AccountsService());
federation.use(credits);
federation.use(payment);
federation.use(new UsageService());
```

从 [Credits Cards](/zh/payments/credits) 开始了解额度模型，支付接入见各 Provider 页面。
