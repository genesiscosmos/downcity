---
title: "Usage 服务"
description: "按当地自然日聚合当前用户的 Credits 消费与 AI 技术用量。"
---

`UsageService` 提供用户自己的每日用量视图。Credits 是消费趋势和热力图的主指标；Token、图片、视频与音频用量来自 `AIService` 的最终计量结果。

Usage 不保存第三份事实：Credits 账务由 `CreditsService` 拥有，AI 技术用量由 `AIService` 拥有，`UsageService` 只通过两个 Reader 聚合结果。

## 安装与启用

```ts
import { AIService } from "@downcity/city";
import { CreditsService, UsageService } from "@downcity/services";

const credits_service = new CreditsService();
const ai_service = new AIService({ credits: credits_service });

federation.use(credits_service);
federation.use(ai_service);
federation.use(new UsageService({
  ai_usage_reader: ai_service,
  credits_usage_reader: credits_service,
}));
```

## 查询当前用户

```ts
const usage = await city.service("usage").get("me", {
  from: "2026-08-01",
  to: "2026-08-31",
  timezone: "Asia/Shanghai",
});
```

`from`、`to` 和 IANA `timezone` 都是必填参数，单次最多查询 400 个当地自然日。响应包含区间汇总和稀疏的每日 Bucket；没有活动的日期不会返回。
