---
title: 查询与汇总
description: "查询当前用户的 Credits 和 AI 每日用量。"
---

Usage 只公开当前用户入口：`GET /v1/usage/me`。身份来自 `user_token`，不能通过参数查询其他用户。

```ts
const usage = await city.service("usage").get("me", {
  from: "2026-03-01",
  to: "2026-03-31",
  timezone: "America/Los_Angeles",
});
```

日期按传入时区的当地自然日划分，包括夏令时切换日。参数必须是真实的 `YYYY-MM-DD` 日期，范围必须有序且不超过 400 天。

## 响应结构

```ts
{
  timezone: "America/Los_Angeles",
  from: "2026-03-01",
  to: "2026-03-31",
  credits_per_usd: 1_000_000,
  data_available_from: { credits: "2026-03-02", ai: "2026-03-02" },
  summary: {
    credits: { used: 2500, charge_count: 3 },
    ai: { execution_count: 3, metered_request_count: 3, total_tokens: 12400 }
  },
  days: [/* 仅包含有 Credits 或 AI 活动的日期 */]
}
```

产品中的热力图和趋势图应优先使用 `days[].credits.used`。Token 和媒体字段用于解释实际 AI 消耗，不应被换算成 Credits，也不能从 Credits 反推。

`data_available_from` 分别表示两个事实源最早可用的当地日期；无数据时为 `null`。
