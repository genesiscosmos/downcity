---
title: Usage 与 Credits 计费
description: Usage 记录事实，业务计算价格，Credits 执行扣费。
---

`UsageService` 保存模型或 Service 调用事实，不拥有价格策略。业务层根据真实 usage 计算 Credits，再调用 `credits.charge()`。

```ts
const ai = new AIService({ credits });

const transaction = await credits.charge({
  user_id: "user_123",
  credits: calculate_credits(usage),
  source: "model_usage",
  ref: usage.request_id,
  idempotency_key: `model_usage:${usage.request_id}`,
  metadata: { model_id: usage.model_id },
});
```

AIService 的 Credits bridge 会在调用前检查最小可用额度，并在得到真实 usage 后扣费。支付订单通过 `PaymentService.on_paid` 给 Primary Card 入账，两条链路不会混合生命周期。
