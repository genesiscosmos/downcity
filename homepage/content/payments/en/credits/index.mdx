---
title: Credits Service
description: Manage permanent Primary Cards and expiring Ephemeral Cards.
---

`CreditsService` owns credit storage and consumption. It does not own payment orders, reward campaign rules, or model pricing.

```ts
import { Federation } from "@downcity/city";
import { CreditsService } from "@downcity/services";

const federation = new Federation({ db });
const credits = new CreditsService();
federation.use(credits);
```

Users can read their current Credits account with `city.service("credits").get("me")`. The response exposes the Primary Card and active Ephemeral Cards as the source of truth, together with the derived `available_credits` total:

```json
{
  "user_id": "user_123",
  "available_credits": 1200000,
  "cards": {
    "primary": {
      "kind": "primary",
      "user_id": "user_123",
      "credits": 1000000,
      "created_at": "2026-07-01T00:00:00.000Z",
      "updated_at": "2026-07-29T10:00:00.000Z"
    },
    "ephemeral": [
      {
        "kind": "ephemeral",
        "card_id": "card_welcome",
        "user_id": "user_123",
        "name": "Welcome credits",
        "credits": 200000,
        "expires_at": "2026-08-05T12:00:00.000Z",
        "source": "welcome",
        "ref": "",
        "created_at": "2026-07-29T00:00:00.000Z",
        "updated_at": "2026-07-29T00:00:00.000Z",
        "status": "active"
      }
    ]
  }
}
```

`ephemeral` contains only active Cards with remaining credits, ordered by earliest expiration. Use Transactions and Card history for depleted or expired credits.

Trusted backends manage credits through the typed `bureau.credits` API. Anonymous subjects, transfers, negative balances, and Card extension or closure are intentionally out of scope.
