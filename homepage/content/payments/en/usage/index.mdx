---
title: "Usage Service"
description: "Aggregate the current user's Credits consumption and AI metering by local calendar day."
---

`UsageService` provides a daily usage view for the current user. Credits are the primary metric for trends and heatmaps. Tokens, images, video, and audio come from the final metering returned by `AIService`.

Usage does not store a third copy of either fact. `CreditsService` owns accounting, `AIService` owns technical usage, and `UsageService` combines both through readers.

## Install and enable

```ts
import { AIService } from "@downcity/federation";
import { CreditsService, UsageService } from "@downcity/services";

const credits_service = new CreditsService();
const ai_service = new AIService({ credits: credits_service });

federation.use(credits_service);
federation.use(ai_service);
federation.use(new UsageService({
  ai_usage_reader: ai_service,
  credits_usage_reader: credits_service,
}));
```

## Query the current user

```ts
const usage = await city.service("usage").get("me", {
  from: "2026-08-01",
  to: "2026-08-31",
  timezone: "America/Los_Angeles",
});
```

`from`, `to`, and the IANA `timezone` are required. A query can cover at most 400 local calendar days. The response contains a range summary and sparse daily buckets; inactive days are omitted.
