---

`@downcity/city/local` 提供 CLI 与 Desktop 共用的本地宿主能力，包括 SQLite Adapter、
路径、产品 Schema、Repository、环境装配与 Plugin Loader。

```ts
import {
  LocalDatabase,
  AgentRepository,
  WorkspaceRepository,
  ensure_local_schema,
} from "@downcity/city/local";

const database = new LocalDatabase({ filename: database_path });
ensure_local_schema(database);

const workspaces = new WorkspaceRepository(database);
const agents = new AgentRepository(root_path);
```

CLI 与 Desktop 在各自组合根中创建这些依赖，读取配置后显式调用 `new Agent()`。
该 local 子入口不创建 Agent、Workspace、Model 或 City。
Workspace 与平台设置以明文 JSON 保存，依靠本地数据库文件的 `0600` 权限进行用户级隔离。
