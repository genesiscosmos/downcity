---
title: "@downcity/local"
description: "CLI 与 Desktop 共用的本地 City Store。"
---

`@downcity/local` 统一读写 `~/.downcity/downcity.db`，恢复 Agent、Workspace、Plugin
Binding、Plugin Resource 和本地 Embassy User Session。

```ts
const city = new City(new LocalCityStore());
await city.ready();
```

CLI 和 Desktop 各自创建独立的 City 实例和宿主生命周期，但使用同一份持久化数据。
