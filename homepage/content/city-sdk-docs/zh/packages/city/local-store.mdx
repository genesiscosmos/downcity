---
title: 本地数据库
description: 使用无业务语义的数据库 Adapter 和独立 Repository 管理本地产品配置。
---

`@downcity/local` 提供本地 SQLite Adapter 和独立 Repository。数据库 Adapter 只提供
SQL 查询、写入、事务和关闭能力，不知道 Agent、Workspace 或 Plugin。

```ts
import {
  AgentRepository,
  LocalDatabase,
  WorkspaceRepository,
} from "@downcity/local";

const database = new LocalDatabase({ filename: database_path });
const workspaces = new WorkspaceRepository(database, crypto_adapter);
const agents = new AgentRepository(database, crypto_adapter, workspaces, secure_settings);
```

CLI 和 Desktop 在各自组合根中创建数据库与 Repository，读取配置后显式调用
`new Agent()`。City 不参与查询、装配或持久化。
