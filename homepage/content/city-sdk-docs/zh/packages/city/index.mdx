title: "@downcity/city"
description: 以明确的生命周期宿主一个或多个 Agent，并统一使用持久化配置。
---

`@downcity/city` 是 CLI、Desktop 和自定义 Node 宿主共用的 Agent 宿主包。它拥有
Agent 集合、本地配置装配和可选 HTTP/RPC transport。

```bash
pnpm add @downcity/city @downcity/agent
```

```ts
import { City, LocalCityStore } from "@downcity/city";

const city = new City(new LocalCityStore());
await city.ready();

const agents = city.agents();
const agent = city.agent("lucas_whitman");

await city.dispose();
```

## 所有权

- `City` 拥有 `CityStore` 恢复出来的 Agent 实例。
- `LocalCityStore` 拥有本地数据库连接，以及 Agent、Workspace、Plugin 的装配。
- CLI 和 Desktop 创建各自独立的 City 实例，但读取同一份 `~/.downcity` 数据。
- Agent 没有启动或停止状态；CLI daemon 或 Desktop 窗口的长期运行属于宿主状态。

单 Agent 执行、Workspace、Session、Plugin SDK 和 RemoteAgent 位于
`@downcity/agent`。Federation、Embassy 和 Bureau 位于 `@downcity/federation`。
