@downcity/city 不再拥有 Federation、Embassy 或 Bureau 实现。它暂时转发旧 Federation API，避免既有应用在 package 迁移期间改变运行结果。

新项目和新代码应直接使用：

~~~bash
pnpm add @downcity/federation
~~~

~~~ts
import { Embassy, Federation } from "@downcity/federation";
~~~

## 当前边界

- Federation 服务端运行时属于 @downcity/federation。
- 用户与管理员客户端统一从 Embassy 进入。
- Bureau 只表示产品或业务分区。
- @downcity/city 不再维护独立实现，也不继续增加新的 Federation API。

旧导出仍由 @downcity/city 转发，但不会形成第二套实现。请阅读 [Federation SDK](/zh/city-sdk-docs/packages/federation-sdk) 了解正式 API。
