title: "@downcity/city"
description: 在内存中索引 Agent，并通过 HTTP/RPC 按 ID 转发请求。
---

`@downcity/city` 是 CLI、Desktop 和自定义 Node 宿主共用的 Agent 转发包。它维护
Agent 的内存索引和可选 HTTP/RPC transport，不读取配置，也不访问数据库。

```bash
pnpm add @downcity/city @downcity/agent
```

```ts
import { Agent } from "@downcity/agent";
import { City } from "@downcity/city";

const agent = new Agent({ id: "lucas", workspace, model, plugins });
const city = new City([agent]);

const current_agent = city.agent("lucas");

await city.close();
await agent.dispose();
```

## 所有权

- CLI、Desktop 或自定义宿主创建并释放 Agent。
- `City` 只维护 `agent_id -> Agent` 的运行时引用和 HTTP/RPC transport。
- `city.add/remove` 只修改内存引用，不创建、释放或持久化 Agent。
- Plugin lifecycle 和 ActionSchedule 归各 Agent 自己拥有。
- CLI daemon 与 Desktop 窗口分别拥有独立的 City 和 Agent 生命周期。

## 宿主协调

CLI 与 Desktop 启动 City 时使用同一份宿主状态。如果另一端已经运行，启动方必须先获得
用户确认，请求已有宿主退出，并等待其释放 transport。这个协议只协调 City 监听权，不给
Agent 增加启动状态，也不修改 Agent、Plugin 或 Session 的持久化数据。

单 Agent 执行、Workspace、Session、Plugin SDK 和 RemoteAgent 位于
`@downcity/agent`。Federation、Embassy 和 Bureau 位于 `@downcity/federation`。
