`@downcity/city` 是 CLI、Desktop 和自定义 Node 宿主共用的 Agent 宿主包。它拥有
Agent 集合、本地配置装配和可选 HTTP/RPC transport。

```bash
pnpm add @downcity/city @downcity/agent
```

```ts
import { City, LocalCityEnvironment, LocalCityStore } from "@downcity/city";

const store = new LocalCityStore();
const environment = new LocalCityEnvironment({ data_source: store });
const city = new City(store, environment);
await city.ready();

const agents = city.agents();
const agent = city.agent("lucas_whitman");

await city.dispose();
```

## 所有权

- `LocalCityStore` 只拥有数据库连接并提供 `CityAgentConfig`。
- `LocalCityEnvironment` 把产品配置转换成纯运行时 `AgentOptions`。
- `City` 调用 `new Agent(options)` 并持有 Agent 实例，也统一拥有 HTTP/RPC transport。
- `city.add/remove` 只管理运行时实例，不读取或修改产品配置。
- Plugin lifecycle 和 ActionSchedule 归各 Agent 自己拥有。
- CLI 和 Desktop 创建各自独立的 City 实例，但读取同一份 `~/.downcity` 数据。
- CLI daemon 与 Desktop 窗口分别拥有独立 City 生命周期，但读取同一份持久化数据。

单 Agent 执行、Workspace、Session、Plugin SDK 和 RemoteAgent 位于
`@downcity/agent`。Federation、Embassy 和 Bureau 位于 `@downcity/federation`。
