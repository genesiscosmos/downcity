## 运行时 package

- [@downcity/federation](/zh/city-sdk-docs/packages/federation)：Federation、Embassy、
  Bureau、Service、鉴权与数据访问。
- [@downcity/city](/zh/city-sdk-docs/packages/city)：多 Agent 宿主、本地持久化装配与
  Agent HTTP/RPC transport。
- [@downcity/agent](/zh/city-sdk-docs/packages/agent)：单 Agent 执行、Workspace、Session、
  Plugin SDK 与 RemoteAgent。
- [CLI](/zh/city-sdk-docs/packages/cli)：`fed/downfed` 管理 Federation，`city/downcity`
  管理本地 Agent 宿主。

官方 Accounts、Credits、Usage 与 Payment Service 位于
[Federation Services](/zh/payments)。
