## 运行时 package

- [@downcity/federation](/zh/city-sdk-docs/packages/federation)：Federation、Embassy、
  Bureau、Service、鉴权与数据访问。
- [@downcity/agent](/zh/city-sdk-docs/packages/agent)：Agent 内存索引与 HTTP/RPC transport。
- [@downcity/local](/zh/city-sdk-docs/packages/local)：产品宿主使用的本地数据库 Adapter、
  配置 Repository 与 Plugin Loader。
- [@downcity/agent](/zh/city-sdk-docs/packages/agent)：单 Agent 执行、AgentWorkspace、Session、
  Plugin SDK 与 RemoteAgent。
- [@downcity/workspace](/zh/city-sdk-docs/packages/workspace)：项目资源、文件、环境变量、
  私有存储和内建 Shell。
- [CLI](/zh/city-sdk-docs/packages/cli)：`fed/downfed` 管理 Federation，`city/downcity`
  管理本地 Agent 宿主。

官方 Accounts、Credits、Usage 与 Payment Service 位于
[Federation Services](/zh/payments)。
