## 运行时 package

- [@downcity/federation](/zh/city-sdk-docs/packages/federation)：Federation、Embassy、
  Bureau、Service、鉴权与数据访问。
- [City](/zh/city-sdk-docs/packages/city)：Agent、Workspace、Plugin、Storage 与 HTTP/RPC transport 的组合根。
- [@downcity/city/local](/zh/city-sdk-docs/packages/local)：产品宿主使用的本地数据库 Adapter、
  配置 Repository 与 Plugin Loader。
- [@downcity/agent](/zh/city-sdk-docs/packages/agent)：Agent、AgentSessions、Session 与执行内核。
- `@downcity/city/plugin`：PluginContext、Action、Hook、Lifecycle 与 City Plugin Module 作者协议。
- [@downcity/city/workspace](/zh/city-sdk-docs/packages/workspace)：项目资源、文件、环境变量、
  内建 Shell，以及 City 使用的底层 Storage Provider。
- [CLI](/zh/city-sdk-docs/packages/cli)：`fed/downfed` 管理 Federation，`city/downcity`
  管理本地 Agent 宿主。

官方 Accounts、Credits、Usage 与 Payment Service 位于
[Federation Services](/zh/payments)。
