---
title: "@downcity/agent"
description: "单 Agent 运行时、Workspace、Session、Plugin SDK 与 RemoteAgent。"
---

`@downcity/agent` 提供单 Agent 执行面，拥有 Agent、Workspace、Session、Plugin SDK 和
RemoteAgent，但不拥有多 Agent 宿主或网络 Server。

```ts
const session = await agent.sessions.create();
const turn = await session.prompt({ query: "你好" });
const result = await turn.finished;
```

CLI、Desktop 或 Node 进程需要持有多个 Agent、恢复本地配置或暴露 HTTP/RPC 时，使用
`@downcity/city`。
