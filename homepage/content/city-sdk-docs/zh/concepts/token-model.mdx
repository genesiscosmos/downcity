## user_token

`user_token` 是给终端用户或产品 client 使用的调用凭证。它由 `FederationAdmin` 基于 `bureau_id + user_id` 向 Federation 申请。

- `bureau_id`
- `user_id`
- `metadata`
- `ttl`

client 只携带 `user_token` 和 `bureau_id`，不接触 provider key，也不接触 `admin_secret_key`。

## admin_secret_key

`DOWNCITY_FEDERATION_ADMIN_SECRET_KEY` 用于管理 Federation：创建 city、管理 env、为某个 city 下的用户签发 `user_token`。Federation 首次启动时会自动生成并写入 Federation env。

```ts
const admin = new FederationAdmin({
  base_url: "https://base.example.com",
  credential: process.env.DOWNCITY_FEDERATION_ADMIN_SECRET_KEY,
});

const bureau = await admin.bureaus.create({
  name: "Chrome Extension",
  server_url: "https://bureau.example.com",
});
```

## 多产品复用

多个 client 可以归属同一个 city。签发 token 时明确写入 `bureau_id`：

```ts
const user = await admin.service("accounts").action("tokens/issue").invoke({
  bureau_id: bureau.bureau_id,
  user_id: "user_123",
  metadata: {
    plan: "pro",
  },
  ttl: "7d",
});

console.log(user.user_token);
```
