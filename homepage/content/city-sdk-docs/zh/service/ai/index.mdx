---
title: AIService
description: 使用 Downcity Model Protocol 注册、路由并执行模型。
---

`AIService` 是 Federation 的模型控制面，统一负责鉴权、模型目录、fallback、reasoning、计量和计费。Agent、City 客户端与 Provider 之间只交换 Downcity Model Protocol，不依赖第三方模型 SDK 类型。

```text
Agent / city.ai.stream()
  -> ModelCall
  -> POST /v1/ai/stream
  -> AIService 路由、fallback、reasoning、计量
  -> AIChannel
  -> Provider Adapter
  -> ModelStreamEvent
```

| 概念 | 职责 |
|---|---|
| `ModelCall` | 消息、文件、工具和生成参数 |
| `ModelClient` | 进程内模型调用接口：`stream(call, signal)` |
| `ModelStreamEvent` | 文本、推理、工具、usage、完成与错误事件 |
| `AIChannel` | Federation 内的上游执行边界 |
| Provider Adapter | Downcity Protocol 与厂商 HTTP 协议互转 |

OpenAI Chat Completions 只作为外部兼容入口，不进入路由和 Channel 的核心类型。
