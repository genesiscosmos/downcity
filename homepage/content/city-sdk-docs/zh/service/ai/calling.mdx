description: 使用 ModelCall、CityModel 和 ModelStreamEvent 调用 Federation 模型。

## 直接调用 Federation

```ts
const stream = await city.ai.stream({
  model: "deepseek-v4-flash",
  call: {
    messages: [{
      role: "user",
      content: [{ type: "text", text: "解释这个仓库" }],
    }],
  },
});

for await (const event of stream) {
  if (event.type === "text_delta") process.stdout.write(event.delta);
}
```

`city.ai.stream()` 返回 `ReadableStream<ModelStreamEvent>`。成功流以 `model_start` 开始，在 `model_finish` 前提供最终 `model_usage`；协议顺序无效时客户端会直接报错。

## 作为 Agent 模型

模型目录返回的对象实现 `ModelClient`，可以直接交给 Agent：

```ts
const catalog = await city.ai.catalog();
const model = catalog.get("deepseek-v4-flash");
const agent = new Agent({ id: "reviewer", model });
```

Agent 负责 Session 上下文、工具循环和审批；Federation 负责最终模型选择与计费。

## 多模态 fallback

Fallback 只检查 `ModelCall.messages` 中最新一条 `role: "user"` 消息的 `file` 内容。历史图片仍完整发送给最终模型，但最新用户消息只有文本时不会再次触发 fallback。末尾即使存在 assistant 或 tool 消息，也会向前定位最近的 user。

## OpenAI-compatible 客户端

需要使用 OpenAI SDK、curl 或现有网关时，调用 `/v1/ai/chat/completions`。该端点会在边界把 OpenAI 请求转换为同一个 `ModelCall`，路由、fallback、reasoning、usage 和计费语义保持一致。
