---
title: Federation Client SDK
description: 按身份选择 Embassy User、Embassy Admin 或 Bureau。
---

客户端 API 对应三个明确身份：

| API | 凭证 | 用途 |
| --- | --- | --- |
| `embassy.user` | User Token | 登录、AI、Payment 与用户 Service |
| `embassy.admin` | Admin Session Token | Federation 管理 |
| `Bureau` | Bureau Token | 可信产品后端与本地 User Token 验签 |

```ts
import { Bureau, Embassy } from "@downcity/federation";

const embassy = new Embassy({ federation_url });
const bureau = new Bureau({ federation_url, bureau_token });
```

不要把 User Token、Admin Session Token 和 Bureau Token 放进同一个共享客户端对象。它们的
所有者、生命周期和信任边界不同。
