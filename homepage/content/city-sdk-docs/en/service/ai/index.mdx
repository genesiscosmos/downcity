---
title: AIService
description: Register, route, and execute models with Downcity Model Protocol.
---

`AIService` is Federation's model control plane. It owns authentication, the model catalog, fallback, reasoning validation, metering, and billing. Agents, City clients, and providers exchange Downcity Model Protocol values rather than third-party model SDK types.

```text
Agent / city.ai.stream()
  -> ModelCall
  -> POST /v1/ai/stream
  -> AIService routing, fallback, reasoning, metering
  -> AIChannel
  -> Provider Adapter
  -> ModelStreamEvent
```

| Concept | Responsibility |
|---|---|
| `ModelCall` | Messages, files, tools, and generation options |
| `ModelClient` | In-process interface: `stream(call, signal)` |
| `ModelStreamEvent` | Text, reasoning, tool, usage, finish, and error events |
| `AIChannel` | Federation's upstream execution boundary |
| Provider Adapter | Converts between Downcity Protocol and a vendor HTTP protocol |

OpenAI Chat Completions remains an external compatibility endpoint; its types do not enter routing or `AIChannel`.
