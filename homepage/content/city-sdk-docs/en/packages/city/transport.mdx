---
title: HTTP and RPC
description: Expose an Agent through the City host transport adapters.
---

`City` owns one HTTP transport and one RPC transport. Both route by `agent_id` to the same Agent
collection and by `workspace_id` to a Workspace owned by City.

```ts
await city.listen({
  http: { host: "127.0.0.1", port: 5314 },
  rpc: { host: "127.0.0.1", port: 15314 },
});

await city.close(); // transports only; the creating host still disposes Agents
```

For separate lifecycle control, City can start either transport directly:

```ts
const http = await city.http({ host: "127.0.0.1", port: 5314 });
const rpc = await city.rpc({ host: "127.0.0.1", port: 15314 });
```

HTTP uses `http://host:port/agents/<agent_id>` and RPC uses `rpc://host:port/<agent_id>`.
There are no Agent-level transport constructors; external services belong to City.
