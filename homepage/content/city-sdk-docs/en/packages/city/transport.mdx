---
title: HTTP and RPC
description: Expose an Agent through the City host transport adapters.
---

`AgentHTTP` and `AgentRPC` belong to the host boundary because they own network resources and
listen/close lifecycles. They do not add a running state to the Agent.

```ts
import { AgentHTTP, AgentRPC } from "@downcity/city";

const rpc = new AgentRPC(agent);
await rpc.listen({ host: "127.0.0.1", port: 15314 });

const http = new AgentHTTP(agent);
await http.server().listen({ host: "127.0.0.1", port: 43127 });

await http.close();
await rpc.close();
```

Use `AgentHTTP.router()` when another Hono server owns the outer HTTP lifecycle.
