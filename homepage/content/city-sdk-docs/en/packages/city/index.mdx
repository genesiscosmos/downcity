title: "@downcity/city"
description: Host one or more Agents with persistent configuration and an explicit lifecycle.
---

`@downcity/city` is the Agent host package used by the CLI, Desktop, and custom Node hosts.
It owns the Agent collection, local configuration assembly, and optional HTTP/RPC transports.

```bash
pnpm add @downcity/city @downcity/agent
```

```ts
import { City, LocalCityStore } from "@downcity/city";

const city = new City(new LocalCityStore());
await city.ready();

const agents = city.agents();
const agent = city.agent("lucas_whitman");

await city.dispose();
```

## Ownership

- `City` owns the Agent instances restored by its `CityStore`.
- `LocalCityStore` owns the local database connection and Agent/Workspace/Plugin assembly.
- The CLI and Desktop create independent City instances but read the same `~/.downcity` data.
- An Agent has no started or stopped state. A long-running CLI daemon or Desktop window is host state.

Single-Agent execution, Workspace, Session, Plugin SDK, and RemoteAgent remain in
`@downcity/agent`. Federation, Embassy, and Bureau belong to `@downcity/federation`.
