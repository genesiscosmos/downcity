---

@downcity/city no longer owns the Federation, Embassy, or Bureau implementation. It temporarily forwards the previous Federation API so existing applications keep the same runtime behavior during the package migration.

New projects and new code should use:

~~~bash
pnpm add @downcity/federation
~~~

~~~ts
import { Embassy, Federation } from "@downcity/federation";
~~~

## Current boundary

- The Federation server runtime belongs to @downcity/federation.
- User and admin access starts from Embassy.
- Bureau only represents a product or business partition.
- @downcity/city does not maintain a separate implementation or accept new Federation APIs.

The previous exports remain available through @downcity/city without creating a second implementation. Read [Federation SDK](/en/city-sdk-docs/packages/federation-sdk) for the canonical API.
