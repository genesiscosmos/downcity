---
title: "@downcity/city"
description: Index Agent instances in memory and route HTTP/RPC requests by ID.
---

`@downcity/city` is the Agent router shared by the CLI, Desktop, and custom Node hosts. It
maintains an in-memory Agent index and optional HTTP/RPC transports. It never reads configuration
or accesses a database.

```bash
pnpm add @downcity/city @downcity/agent
```

```ts
import { Agent } from "@downcity/agent";
import { City } from "@downcity/city";

const agent = new Agent({ id: "lucas", workspace, model, plugins });
const city = new City([agent]);

const current_agent = city.agent("lucas");

await city.close();
await agent.dispose();
```

## Ownership

- The CLI, Desktop, or custom host creates and disposes Agents.
- `City` only maintains `agent_id -> Agent` runtime references and HTTP/RPC transports.
- `city.add/remove` only update in-memory references. They never create, dispose, or persist Agents.
- Each Agent owns its Plugin lifecycle and ActionSchedule.
- The CLI daemon and Desktop window own independent City and Agent lifecycles.

Single-Agent execution, Workspace, Session, Plugin SDK, and RemoteAgent remain in
`@downcity/agent`. Federation, Embassy, and Bureau belong to `@downcity/federation`.
