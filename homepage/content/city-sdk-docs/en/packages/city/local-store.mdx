---
title: Local Database
description: Manage local product configuration with a business-neutral database adapter and repositories.
---

`@downcity/local` provides a local SQLite adapter and independent repositories. The database
adapter only provides query, mutation, transaction, and close operations. It does not know about
Agents, Workspaces, or Plugins.

```ts
import {
  AgentRepository,
  LocalDatabase,
  WorkspaceRepository,
} from "@downcity/local";

const database = new LocalDatabase({ filename: database_path });
const workspaces = new WorkspaceRepository(database, crypto_adapter);
const agents = new AgentRepository(database, crypto_adapter, workspaces, secure_settings);
```

The CLI and Desktop create databases and repositories in their own composition roots, read
configuration, and call `new Agent()` explicitly. City never queries, assembles, or persists data.
