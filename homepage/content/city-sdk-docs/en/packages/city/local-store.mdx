---
title: Local Store
description: Read the product configuration needed to assemble Agents from ~/.downcity.
---

`LocalCityStore` is the pure-data adapter shared by CLI and Desktop hosts. It reads and writes
Agent, Workspace, Plugin Binding, Resource, and Installation records in
`~/.downcity/downcity.db`. It never creates an Agent, Workspace, Model, Plugin, or Embassy.

```ts
import { City, LocalCityEnvironment, LocalCityStore } from "@downcity/city";

const store = new LocalCityStore();
const environment = new LocalCityEnvironment({ data_source: store });
const city = new City(store, environment);
await city.ready();
```

During initialization, City calls `store.load_agent_configs()` and asks the Environment for
runtime-only `AgentOptions`. This assembles a new instance from configuration; there is no Agent
serialization or restoration protocol.

The product creates, updates, and deletes configuration through `LocalCityStore` APIs.
`city.add(agent)` registers an existing instance, while `city.remove(agent_id)` removes and
disposes it. Neither method changes configuration or Session data.

For tests or temporary hosts, use `MemoryCityStore` instead.
