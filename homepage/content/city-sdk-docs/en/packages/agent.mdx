---
title: "@downcity/agent"
description: "Single-Agent runtime, Workspace, Session, Plugin SDK, and RemoteAgent."
---

`@downcity/agent` provides the single-Agent execution surface. It owns Agent, Workspace,
Session, Plugin SDK, and RemoteAgent, but does not own a multi-Agent host or network server.

```ts
const session = await agent.sessions.create();
const turn = await session.prompt({ query: "Hello" });
const result = await turn.finished;
```

Use `@downcity/city` when a CLI, Desktop application, or Node process needs to own multiple
Agent instances, restore local configuration, or expose HTTP/RPC transports.
