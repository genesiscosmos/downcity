## Runtime packages

- [@downcity/federation](/en/city-sdk-docs/packages/federation): Federation, Embassy, Bureau,
  Services, auth, and data access.
- [City](/en/city-sdk-docs/packages/city): the composition root for Agents, Workspaces, Plugins, Storage, and HTTP/RPC transports.
- [@downcity/city/local](/en/city-sdk-docs/packages/local): local database adapter, configuration
  repositories, and Plugin loader used by product hosts.
- [@downcity/agent](/en/city-sdk-docs/packages/agent): Agent, AgentSessions, Session, and the execution runtime.
- `@downcity/city/plugin`: author contracts for PluginContext, Actions, Hooks, Lifecycle, and City Plugin Modules.
- [@downcity/city/workspace](/en/city-sdk-docs/packages/workspace): project resources, files,
  environment, built-in Shell, and low-level storage providers used by City.
- [CLI](/en/city-sdk-docs/packages/cli): `fed/downfed` manages Federation;
  `city/downcity` manages the local Agent host.

Official Accounts, Credits, Usage, and Payment Services are documented in
[Federation Services](/en/payments).
