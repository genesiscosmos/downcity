---
title: Issue a User Token
description: Ask Federation to issue a user credential through Embassy Admin.
---

```ts
import { Embassy } from "@downcity/federation";

const embassy = new Embassy({
  federation_url: "https://fed.example.com",
  admin_token: administrator_session_token,
});

const issued = await embassy.admin.service("accounts")
  .action("tokens/issue")
  .invoke({
    bureau_id: "product-web",
    user_id: "user_123",
    metadata: { plan: "pro" },
    ttl: "7d",
  });
```

Federation performs the issuance. Bureau verifies User Tokens but does not issue them.
