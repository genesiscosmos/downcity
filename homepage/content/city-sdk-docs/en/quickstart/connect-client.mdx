---
title: Connect Embassy
description: Call Federation AI and Services through Embassy User.
---

```ts
import { Embassy } from "@downcity/federation";

const embassy = new Embassy({
  federation_url: "https://fed.example.com",
  user_token: "ub_xxx",
});

const catalog = await embassy.user.ai.catalog();
const model = catalog.get("gpt-5.4");
if (!model) throw new Error("model not found");

const result = await embassy.user.ai.text({
  model,
  prompt: "Write a welcome message",
});
```

Use `embassy.user.service(name)` for custom or official Services. Provider keys, model routing,
and usage accounting remain inside Federation.
