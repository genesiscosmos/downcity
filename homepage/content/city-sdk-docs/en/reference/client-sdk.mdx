---
title: Federation Client SDK
description: Choose Embassy User, Embassy Admin, or Bureau by identity.
---

The client API follows three explicit identities:

| API | Credential | Purpose |
| --- | --- | --- |
| `embassy.user` | User Token | Login, AI, payment, and user Services |
| `embassy.admin` | Admin Session Token | Federation administration |
| `Bureau` | Bureau Token | Trusted product backend and local User Token verification |

```ts
import { Bureau, Embassy } from "@downcity/federation";

const embassy = new Embassy({ federation_url });
const bureau = new Bureau({ federation_url, bureau_token });
```

Do not place User Tokens, Admin Session Tokens, and Bureau Tokens in one shared client object.
Their owners, lifetimes, and trust boundaries are different.
