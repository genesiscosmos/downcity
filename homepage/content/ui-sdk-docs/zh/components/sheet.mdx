`Sheet` 适合承载比 `Dialog` 更长、更像面板的内容。

## 导入

```tsx
import {
  Sheet,
  SheetTrigger,
  SheetContent,
  SheetHeader,
  SheetTitle,
  SheetDescription,
  SheetFooter,
  Button,
} from "@downcity/ui";
```

## 最小示例

<ComponentPreview name="sheet" />

## 可用方向

- `top`
- `right`
- `bottom`
- `left`

## 使用建议

- 长表单优先用 `Sheet`
- `SheetTitle` 不要省略
- 关闭按钮可通过 `showCloseButton={false}` 关闭
