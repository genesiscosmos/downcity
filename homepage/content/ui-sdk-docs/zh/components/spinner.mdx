# Spinner

`Spinner` 继承当前文本颜色，可组合进按钮、Item、菜单和空状态。

```tsx
import { Button, Spinner } from "@downcity/ui";

export function SavingButton() {
  return <Button disabled><Spinner /> 保存中</Button>;
}
```

支持 `sm`、`default`、`lg` 三种尺寸。组件仅负责视觉反馈，异步任务生命周期由宿主管理。
