`Dialog` 用于需要暂时打断当前上下文的弹窗场景。

## 导入

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
  DialogFooter,
  Button,
} from "@downcity/ui";
```

## 使用建议

- `DialogTitle` 不要省略
- 内容很多时优先换成 [Sheet](/zh/ui-sdk-docs/components/sheet)
- 关闭按钮可通过 `showCloseButton={false}` 关闭
