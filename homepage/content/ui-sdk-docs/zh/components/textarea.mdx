`Textarea` 用于多行文本编辑。

## 导入

```tsx
import { Textarea, Label } from "@downcity/ui";
```

## 最小示例

<ComponentPreview name="textarea" />

## 适合场景

- Prompt
- 说明文本
- 多行配置片段

## 相关导出

- `Textarea`
- `TextareaProps`

## 使用建议

- 长文本统一用 `Textarea`
- 如果只是简短字段，优先使用 [Input](/zh/ui-sdk-docs/components/input)
