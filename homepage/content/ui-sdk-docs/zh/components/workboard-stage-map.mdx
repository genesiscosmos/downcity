并不存在公开的 `WorkboardStageMap` 组件。它是组合式 [Workboard](./workboard) atlas 内部使用的
像素村庄 renderer：依据游戏地图几何信息绘制建筑、房间与路径，用来表达 agent 活动分区。

`@downcity/ui` 不导出这个 renderer。渲染 `Workboard` 并交由它绘制 atlas 即可。

## 哪些是公开的

这张地图所绘制的几何信息来自导出的构造函数：

```tsx
import { buildWorkboardGameMapConfig } from "@downcity/ui";

const gameMap = buildWorkboardGameMapConfig({
  board,
  activeZoneId: "active",
  selectedAgentId,
});
```

`gameMap.zones`、`gameMap.pointsOfInterest` 与 `gameMap.actors` 就是像素地图所渲染的值。
需要复用同一套布局时，构建一次并交给自己的覆盖层使用。
