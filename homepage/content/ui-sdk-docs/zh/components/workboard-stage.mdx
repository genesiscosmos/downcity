description: 组合式 Workboard 内部的舞台层
---
并不存在公开的 `WorkboardStage` 组件。舞台层是组合式 [Workboard](./workboard) 的内部实现：
它是一个固定尺寸的坐标空间，用来摆放分区与 agent 节点。

`@downcity/ui` 不导出这个舞台组件，也不导出它的分区定义与坐标辅助函数。渲染 `Workboard`
并交由它管理舞台即可。

## 哪些是公开的

board 的游戏几何信息只能通过一个导出的构造函数获得：

```tsx
import { buildWorkboardGameMapConfig } from "@downcity/ui";

const gameMap = buildWorkboardGameMapConfig({
  board,
  activeZoneId: "active",
  selectedAgentId,
});
```

`buildWorkboardGameMapConfig` 返回 `DowncityWorkboardGameMapConfig`，描述 zones、actors、
corridors、patrols 与 points of interest，也就是舞台所渲染的同一套几何信息。
