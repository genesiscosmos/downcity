`Skeleton` 用于等待数据时的占位骨架。

## 导入

```tsx
import { Skeleton } from "@downcity/ui";
```

## 最小示例

<ComponentPreview name="skeleton" />

## 使用建议

- 通过 `className` 决定尺寸和形状
- 与真实布局尽量保持一致
- 不要用 `Skeleton` 承载真实内容
