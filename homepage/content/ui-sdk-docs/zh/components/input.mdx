`Input` 是最常用的单行输入组件。

## 导入

```tsx
import { Input, Label } from "@downcity/ui";
```

## 最小示例

<ComponentPreview name="input" />

## 适合场景

- 单行文本
- 搜索框
- 模型名、路径、键值等短字段

## 使用建议

- 配合 `Label` 使用
- 长文本请切换到 [Textarea](/zh/ui-sdk-docs/components/textarea)
- 错误态优先通过原生 `aria-invalid` 传达
