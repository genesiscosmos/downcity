## Usage Notes

- Use `size="sm"` or `size="default"` for page-level actions
- Use `variant="ghost"` for toolbar controls
- Use `variant="destructive"` for destructive actions
- Prefer `icon-*` sizes instead of hand-written `w-* h-*`
