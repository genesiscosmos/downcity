There is no public `WorkboardStageMap` component. It is the pixel-art village renderer used inside
the composite [Workboard](./workboard) atlas: buildings, rooms, and paths are drawn from the game
map geometry to represent agent activity zones.

`@downcity/ui` does not export this renderer. Render `Workboard` and let it draw the atlas.

## What is public

The geometry this map draws comes from the exported builder:

```tsx
import { buildWorkboardGameMapConfig } from "@downcity/ui";

const gameMap = buildWorkboardGameMapConfig({
  board,
  activeZoneId: "active",
  selectedAgentId,
});
```

`gameMap.zones`, `gameMap.pointsOfInterest`, and `gameMap.actors` are the values the pixel map
renders. Build them once and pass them to your own overlay when you need the same layout.
