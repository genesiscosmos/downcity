`Dialog` is for modal interactions that temporarily block the current context.

## Import

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
  DialogFooter,
  Button,
} from "@downcity/ui";
```

## Usage Notes

- Do not omit `DialogTitle`
- Prefer `Sheet` when the content is long or panel-like
- Use `showCloseButton={false}` if you need to disable the built-in close button
