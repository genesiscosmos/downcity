There is no public `WorkboardStage` component. The stage is an internal layer of the composite
[Workboard](./workboard): a fixed-size coordinate space where zones and agent nodes are positioned.

`@downcity/ui` does not export the stage component, its zone definitions, or its coordinate helpers.
Render `Workboard` and let it own the stage.

## What is public

The board's game geometry is reachable through one exported builder:

```tsx
import { buildWorkboardGameMapConfig } from "@downcity/ui";

const gameMap = buildWorkboardGameMapConfig({
  board,
  activeZoneId: "active",
  selectedAgentId,
});
```

`buildWorkboardGameMapConfig` returns a `DowncityWorkboardGameMapConfig` describing zones, actors,
corridors, patrols, and points of interest — the same geometry the stage renders.
