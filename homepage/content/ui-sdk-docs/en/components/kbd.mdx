# Kbd

`Kbd` uses semantic keyboard markup, while `KbdGroup` arranges multiple keys.

```tsx
import { Kbd, KbdGroup } from "@downcity/ui";

export function SearchShortcut() {
  return <KbdGroup><Kbd>⌘</Kbd><Kbd>K</Kbd></KbdGroup>;
}
```

It displays a shortcut but does not register or handle keyboard events.
