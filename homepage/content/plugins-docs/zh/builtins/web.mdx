# web Plugin

`web` 由 WebPlugin 自己持有搜索、网页读取和浏览器 Provider，不依赖
`context.agent.web`。Desktop 安装后无需手工启动浏览器：静态网页读取和本地 Chrome
浏览器默认可用，搜索在配置 API Key 后启用。

## Desktop 配置

进入「Plugins → Web」。配置分为三个能力区：

- 搜索：`Auto`、`Tavily`、`Exa` 或关闭。Auto 优先使用 Tavily，其次 Exa。
- 网页读取：默认 `Built-in Fetch`，也可以选择 Firecrawl。
- 浏览器：默认 `Local Chrome`，也可以切换为远程 CDP 或关闭。

API Key 可以直接在 Web 配置页写入。已保存的 Key 只显示“已配置”，不会回显明文；
空输入会保留旧 Key，只有点击“清除”并保存才会删除。Key 当前保存在 Downcity 本地
Plugin 配置文件中，尚未使用系统钥匙串。

也可以在「设置 → Global Env」写入：

```dotenv
TAVILY_API_KEY=...
EXA_API_KEY=...
FIRECRAWL_API_KEY=...
```

Web 配置页中的 Key 优先于 Global Env。每个能力区都提供测试按钮；测试会先保存当前
配置，再通过一个真实 Agent 和 Workspace 执行最小调用。

## 默认行为

```ts
import { WebPlugin } from "@downcity/plugins/web";

const web = new WebPlugin();
```

- `open` 使用内建 Fetch，只读取公网 HTTP(S) 页面，不执行页面脚本。
- 浏览器自动发现 Google Chrome、Chromium 或 Microsoft Edge，并使用 Plugin 私有的持久 profile。
- `search` 在找到 Tavily 或 Exa Key 后启用；没有 Key 时只禁用搜索，不影响其他能力。

本地浏览器进程和它创建的页面由 WebPlugin 负责关闭。持久 profile 保留用户主动建立的
登录状态。若需要云浏览器，将 Browser Provider 切换为 `Remote CDP` 并填写 HTTP 或
WebSocket endpoint。

## SDK 固定配置

构造配置的优先级高于 City/Desktop 保存的配置：

```ts
const web = new WebPlugin({
  config: {
    search_provider: "tavily",
    tavily_api_key: process.env.TAVILY_API_KEY,
    document_provider: "firecrawl",
    firecrawl_api_key: process.env.FIRECRAWL_API_KEY,
    browser_provider: "cdp",
    cdp_url: "https://browser.example.com/cdp",
  },
});
```

宿主仍可注入自定义 `search_provider`、`document_provider` 或
`browser_provider_factory`。注入对象的生命周期所有权转移给 WebPlugin。

## Actions

| Action | 用途 |
|---|---|
| `search` | 使用 Tavily、Exa 或注入的搜索 Provider |
| `open` | 使用安全 Fetch、Firecrawl 或注入的文档 Provider |
| `browser_create_session` | 创建浏览器 Session |
| `browser_observe` | 读取 URL、标题、Accessibility Snapshot、可见文本、元素 ref 和可选截图 |
| `browser_act` | 使用 observation generation + ref 执行确定性动作 |
| `browser_semantic_act` | 通过可选语义 Adapter 执行自然语言动作 |
| `browser_extract` | 按 CSS selector 或 body 抽取文本 |
| `browser_semantic_extract` | 通过可选语义 Adapter 抽取内容 |
| `browser_close_session` | 关闭 Session 并释放页面 |

先观察，再使用该代观察中的 ref：

```ts
const observed = await web.actions.browser_observe.execute({
  context,
  input: { session_id },
});

await web.actions.browser_act.execute({
  context,
  input: {
    session_id,
    action: {
      type: "click",
      ref: observed.data.elements[0].ref,
      observation_generation: observed.data.observation_generation,
    },
  },
});
```

元素 ref 只在生成它的 observation generation 内有效。动作返回新观察后必须使用新的
ref；CSS selector 仅保留给显式的确定性自动化。

## 网络与安全边界

- Fetch 只允许公网 HTTP(S)，每次重定向都重新检查目标并阻止本机、私网和链路本地地址。
- 网络请求限制超时、重定向次数和响应大小。
- Provider 错误不返回 API Key、认证请求头或完整错误响应正文。
- 提交、发送、购买、上传和删除等副作用仍必须经过宿主审批。
- 页面内容始终视为不可信输入，不能覆盖 Agent 或宿主指令。
