This section is the concrete power manual.

Use it when you want to understand a specific power such as `web`, `skill`, `messenger`, or `task`.

If you want power design concepts first, continue with [Power Overview](/en/agent-sdk-docs/powers/overview) in Agent SDK Docs.

## What this section covers

- which built-in powers currently exist in code
- which built-in power classes are publicly exported from `@downcity/powers`
- which ones are mainly platform-managed or infrastructure-oriented
- what each power is responsible for
- what lifecycle, availability, config, and action shape each power has

## Reading paths

- Start with [Built-ins Overview](/en/powers-docs/builtins/overview)
- Then open the power you care about
- Use [Examples](/en/powers-docs/examples) when you want scenario-driven patterns

## Best mental model

There are two different questions:

1. how the power system itself works
2. what one concrete power actually does

This section answers the second question.
