## Scenario

You want one power to provide a read-only snapshot endpoint:

- `GET /api/notes/snapshot`

That is a clean fit for `power.http.server`.

## Current boundary

This capability belongs to the full runtime HTTP assembly path.

That means:

- `power.http.server` is not the same kind of explicit call as `city.powers.scope({ agent_id: agent.id, workspace_id: workspace.id }).run_action(...)`
- Downcity exposes HTTP and automatically mounts power HTTP routes for the running Agent
- if you need this, think of it as a fuller host/runtime integration capability
