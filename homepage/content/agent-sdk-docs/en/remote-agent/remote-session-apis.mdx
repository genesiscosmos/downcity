# Remote Session API

Remote Sessions provide `get_info()`, `prompt()`, `stop()`, `subscribe()`, `messages()`,
`system()`, `interactions()`, `respond()`, `status()`, `set({ security })`, and `fork()`.

```ts
const session = await agent.sessions.create();

const unsubscribe = session.subscribe(apply_mutation);
const turn = await session.prompt({ query: "Continue" });
await turn.finished;

const page = await session.messages();
const status = await session.status();

await session.set({
  security: { approval_mode: "always-allow" },
});
unsubscribe();
```

The subscription emits `message | part | delta | turn | file_diff | session | warning`. User participation is a pending Interaction Part while its related Tool is `waiting-user`; a failed model call emits `warning / model_request`. Submit structured user responses with `session.respond(...)`.

Remote clients can set serializable security policy but do not select models through the Agent SDK.
The server host owns model IDs, defaults, recovery, and runtime instance injection.
