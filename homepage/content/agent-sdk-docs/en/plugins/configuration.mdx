# Plugin Configuration

The Agent SDK only runs already constructed Plugin instances. It does not read City install directories or Profiles:

```ts
await agent.plugins.register(new SkillPlugin());
await agent.plugins.unregister("skill");
```

## SDK hosts

An embedded host passes runtime configuration directly through Plugin constructors. Their shape belongs entirely to the Plugin author:

```ts
import { ChatPlugin, TelegramChannel } from "@downcity/plugins/chat";

const chat_plugin = new ChatPlugin({
  queue: { max_concurrency: 4 },
  channels: [
    new TelegramChannel({
      id: "telegram_main",
      name: "Main Bot",
      bot_token: process.env.TELEGRAM_BOT_TOKEN ?? "",
    }),
  ],
});

await agent.plugins.register(chat_plugin);
```

The SDK host owns credential sources, configuration UI, and instance assembly. It does not need Profiles.

## CLI / Desktop hosts

A generic host cannot guess arbitrary Plugin constructors, so it uses the optional `agent` factory from an installable Plugin package:

```text
Plugin Catalog
→ user manages a Profile in Config under Settings / Plugins
→ Agent stores plugin_id → profile_id for a Plugin with Config
→ host reads the Profile snapshot and calls the agent factory
→ Agent Runtime Plugin
```

A Profile is only named configuration space for a Plugin that declares Config; it is unrelated to the Sidebar/Mainview workspace. The host creates, selects, removes, and persists Profiles. Plugin-owned Config actions validate content and provide safe projections, while the `config` slot owns editing. A Plugin without Config needs no Profile, and the Agent stores only its enabled state. The host does not generate generic JSON Schema forms or put channels, accounts, or tokens in `agent.json`.

## Recommended mental model

- Agent SDK: accepts and runs Plugin objects.
- SDK host: constructs Plugins directly and owns its configuration source.
- CLI / Desktop: owns the Catalog, installation, Profiles, and Agent references.
- Plugin: owns its business configuration, Config actions, and Config UI.
