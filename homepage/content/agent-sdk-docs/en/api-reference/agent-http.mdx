# AgentHTTP

`AgentHTTP` is the HTTP transport for one local `AgentWorkspace`. It exposes its RemoteAgent Session API and approval operations over HTTP.

Only available when you install `@downcity/city`:

```bash
pnpm add @downcity/city
```

## Minimal usage

```ts
import { AgentHTTP } from "@downcity/city";
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";

const agent = new Agent({
  id: "demo",
  model,
});
const agent_workspace = agent.enter(new Workspace({ id: "project", path: process.cwd() }));
const http = new AgentHTTP(agent_workspace);

const binding = await http.server().listen({ host: "127.0.0.1", port: 5314 });
// HTTP server listening on http://127.0.0.1:5314
```

## Constructor

```ts
new AgentHTTP(agent_workspace: AgentWorkspace)
```

| Param | Type | Description |
|-------|------|-------------|
| `agent_workspace` | `AgentWorkspace` | The local Agent execution scope to expose |

## Methods

### `listen(options)`

Start the HTTP server.

```ts
const binding = await http.server().listen({
  host: "127.0.0.1",  // optional: bind address (default: "127.0.0.1")
  port: 5314,            // required: TCP port
});
```

Returns `AgentHttpBinding` with the server URL, host, and port. Use `router()` before startup when you need to mount the transport on your own Hono app.

### `close()`

Stop the HTTP server.

```ts
await http.close();
```

## Endpoints

The HTTP server exposes a RESTful interface for session management, execution, and health checks. For the exact route table, see [HTTP Endpoints](/en/agent-sdk-docs/api-reference/sdk-http-endpoints).

## When to use it

- You want to access an agent session from a browser or mobile app
- You are building a local dev server with an agent backend
- You need to integrate with HTTP middleware or existing web infrastructure

See also: [AgentRPC](/en/agent-sdk-docs/api-reference/agent-rpc) for the lightweight RPC transport.
