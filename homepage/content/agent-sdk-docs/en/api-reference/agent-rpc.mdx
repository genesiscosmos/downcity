# AgentRPC

`AgentRPC` is the TCP RPC transport for one locally running `AgentWorkspace`. It lets other processes access that Workspace's Sessions without going through HTTP.

Only available when you install `@downcity/agent`:

```bash
pnpm add @downcity/agent
```

## Minimal usage

```ts
import { AgentRPC } from "@downcity/agent/city";
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";

const agent = new Agent({
  id: "demo",
  model,
});
const agent_workspace = agent.enter(new Workspace({ id: "project", path: process.cwd() }));
const rpc = new AgentRPC(agent_workspace);

const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
```

## Constructor

```ts
new AgentRPC(agent_workspace: AgentWorkspace)
```

| Param | Type | Description |
|-------|------|-------------|
| `agent_workspace` | `AgentWorkspace` | The local Agent execution scope to expose |

## Methods

### `listen(options?)`

Start listening for RPC connections.

```ts
const binding = await rpc.listen({
  host: "127.0.0.1",
  port: 15314,
});
```

Returns `AgentRpcBinding` containing the TCP endpoint information.

### `close()`

Stop the RPC server and release resources.

```ts
await rpc.close();
```

## When to use it

- You want another local process to access the same agent sessions
- You are building a local multi-process architecture
- You want a lightweight RPC transport without HTTP overhead

See also: [AgentHTTP](/en/agent-sdk-docs/api-reference/agent-http) for the HTTP transport layer.
