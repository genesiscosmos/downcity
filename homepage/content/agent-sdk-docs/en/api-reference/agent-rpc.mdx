# AgentRPC

`AgentRPC` is the TCP RPC transport for a locally running `Agent`. It lets other processes or services access the agent's sessions through a host and port without going through HTTP.

Only available when you install `@downcity/city`:

```bash
pnpm add @downcity/city
```

## Minimal usage

```ts
import { AgentRPC } from "@downcity/city";
import { Agent, Workspace } from "@downcity/agent";

const agent = new Agent({
  id: "demo",
  workspace: new Workspace({ path: process.cwd() }),
  model,
});
const rpc = new AgentRPC(agent);

const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
```

## Constructor

```ts
new AgentRPC(agent: Agent)
```

| Param | Type | Description |
|-------|------|-------------|
| `agent` | `Agent` | A fully constructed local Agent instance |

## Methods

### `listen(options?)`

Start listening for RPC connections.

```ts
const binding = await rpc.listen({
  host: "127.0.0.1",
  port: 15314,
});
```

Returns `AgentRpcBinding` containing the TCP endpoint information.

### `close()`

Stop the RPC server and release resources.

```ts
await rpc.close();
```

## When to use it

- You want another local process to access the same agent sessions
- You are building a local multi-process architecture
- You want a lightweight RPC transport without HTTP overhead

See also: [AgentHTTP](/en/agent-sdk-docs/api-reference/agent-http) for the HTTP transport layer.
