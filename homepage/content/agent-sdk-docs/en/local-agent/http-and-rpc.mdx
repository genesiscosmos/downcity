# Expose Agent over RPC and HTTP

`@downcity/agent` only constructs Agents and runs sessions. Network exposure lives in a separate package, `@downcity/city`. Install and start it on demand.

```bash
pnpm add @downcity/agent @downcity/city
```

## Agent has no `start()` anymore

After `new Agent(...)`, plugin lifecycle and ActionSchedule start automatically. You do not need to call `start()`.

- Session execution waits for Plugin lifecycle and ActionSchedule startup internally.
- `await agent.dispose()`: release Agent-owned runtime resources (plugins, ActionSchedule, shell).

RPC and HTTP are no longer Agent responsibilities.

## AgentRPC: expose as local RPC

`AgentRPC` exposes one `AgentWorkspace` over NDJSON-on-TCP for `RemoteAgent("rpc://...")`.

```ts
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";
import { AgentRPC } from "@downcity/agent/city";

const workspace = new Workspace({ id: "project", path });
const agent = new Agent({ id, model });
const agent_workspace = agent.enter(workspace);
const rpc = new AgentRPC(agent_workspace);
const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
console.log(binding.url); // rpc://127.0.0.1:15314

// shutdown
await rpc.close();
await agent.dispose();
```

`AgentRPC` defaults to `127.0.0.1:15314`. The protocol is NDJSON, no auth. Use it on local or trusted networks.

## AgentHTTP: expose minimal SDK HTTP surface

`AgentHTTP` provides the minimal HTTP surface (`/api/sdk/sessions/*`) consumed by the `RemoteAgent` HTTP client. Two usage modes; pick one.

### Mode 1: standalone HTTP server

```ts
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";
import { AgentHTTP } from "@downcity/agent/city";

const workspace = new Workspace({ id: "project", path });
const agent = new Agent({ id, model });
const agent_workspace = agent.enter(workspace);
const http = new AgentHTTP(agent_workspace);
const binding = await http.server().listen({ host: "127.0.0.1", port: 5314 });
console.log(binding.url); // http://127.0.0.1:5314

// shutdown
await http.close();
await agent.dispose();
```

### Mode 2: mount onto your own Hono server

`AgentHTTP.router()` returns a `Hono` sub-router. Mount it directly:

```ts
import { Hono } from "hono";
import { AgentHTTP } from "@downcity/agent/city";

const app = new Hono();
const http = new AgentHTTP(agent_workspace);
app.route("/", http.router());
```

CORS / logger / auth middleware are your responsibility. `AgentHTTP` does not attach any.

## Relationship with Downcity and RemoteAgent

- `downcity on` creates one `City`, restores all Agents, and starts one City HTTP port plus one City RPC port.
- City HTTP URLs use `http://127.0.0.1:5314/agents/<agent_id>`; City RPC URLs use `rpc://127.0.0.1:15314/<agent_id>`.
- `RemoteAgent` clients can connect to the `rpc://` URL exposed by `AgentRPC.listen()` or to the HTTP surface exposed by `AgentHTTP`.
