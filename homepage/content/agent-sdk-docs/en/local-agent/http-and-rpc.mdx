# Expose City over RPC and HTTP

External services belong to `City`. Agents remain the execution subjects; City owns the network listeners and routes requests to its Agents and Workspaces.

```bash
pnpm add @downcity/agent @downcity/agent
```

## Agent has no `start()` anymore

After `new Agent(...)`, plugin lifecycle and ActionSchedule start automatically. You do not need to call `start()`.

- Session execution waits for Plugin lifecycle and ActionSchedule startup internally.
- `await agent.dispose()`: release Agent-owned runtime resources (plugins, ActionSchedule, shell).

RPC and HTTP are no longer Agent responsibilities.

## City RPC

`city.rpc()` exposes all City Agents over NDJSON-on-TCP for `RemoteAgent("rpc://...")`.

```ts
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";
import { City } from "@downcity/agent";

const workspace = new Workspace({ id: "project", path });
const agent = new Agent({ id, model });
// Session 在创建时选择 Workspace。
const city = new City({ workspaces: [workspace] });
city.agents.add(agent);
const rpc = await city.rpc({ host: "127.0.0.1", port: 15314 });
console.log(binding.url); // rpc://127.0.0.1:15314

// shutdown
await city.close();
```

`AgentRPC` defaults to `127.0.0.1:15314`. The protocol is NDJSON, no auth. Use it on local or trusted networks.

## City HTTP

`city.http()` provides the HTTP surface consumed by the `RemoteAgent` HTTP client.

### Mode 1: standalone HTTP server

```ts
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";
import { City } from "@downcity/agent";

const workspace = new Workspace({ id: "project", path });
const agent = new Agent({ id, model });
// Session 在创建时选择 Workspace。
const city = new City({ workspaces: [workspace] });
city.agents.add(agent);
const http = await city.http({ host: "127.0.0.1", port: 5314 });
console.log(binding.url); // http://127.0.0.1:5314

// shutdown
await city.close();
```

City owns the listener and the complete Agent routing table. CORS, logger and auth are configured by the City host.

## Relationship with Downcity and RemoteAgent

- `downcity on` creates one `City`, restores all Agents, and starts one City HTTP port plus one City RPC port.
- City HTTP URLs use `http://127.0.0.1:5314/agents/<agent_id>`; City RPC URLs use `rpc://127.0.0.1:15314/<agent_id>`.
- `RemoteAgent` clients can connect to the `rpc://` URL exposed by `city.rpc()` or to the HTTP surface exposed by `city.http()`.
