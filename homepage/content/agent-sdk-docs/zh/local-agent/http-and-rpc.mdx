# 通过 RPC 与 HTTP 暴露 Agent

`@downcity/agent` 只负责构造 Agent 和运行会话。网络暴露能力放在独立包 `@downcity/city` 里，按需引入。

```bash
pnpm add @downcity/agent @downcity/city
```

## Agent 不再有 `start()`

`new Agent(...)` 之后，plugin lifecycle 和 ActionSchedule 会自动启动。无需再手动调用 `start()`。

- Session 执行会在内部等待 Plugin lifecycle 与 ActionSchedule 启动完成。
- `await agent.dispose()`：释放 Agent 自有运行时资源（plugins、ActionSchedule、shell）。

RPC 与 HTTP 不再是 Agent 的职责。

## AgentRPC：暴露为本机 RPC

`AgentRPC` 把 `Agent` 通过 NDJSON-over-TCP 暴露给 `RemoteAgent("rpc://...")` 使用。

```ts
import { Agent, Workspace } from "@downcity/agent";
import { AgentRPC } from "@downcity/city";

const workspace = new Workspace({ path });
const agent = new Agent({
  id,
  workspace,
  model,
});
const rpc = new AgentRPC(agent);
const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
console.log(binding.url); // rpc://127.0.0.1:15314

// 关闭
await rpc.close();
await agent.dispose();
```

`AgentRPC` 默认监听 `127.0.0.1:15314`，协议为 NDJSON，无鉴权，仅用于本机或可信网络。

## AgentHTTP：暴露最小 SDK HTTP 表面

`AgentHTTP` 提供 `RemoteAgent` HTTP 客户端所需的最小 HTTP 表面（`/api/sdk/sessions/*`）。两种用法二选一。

### 方式 1：独立 HTTP server

```ts
import { Agent, Workspace } from "@downcity/agent";
import { AgentHTTP } from "@downcity/city";

const workspace = new Workspace({ path });
const agent = new Agent({
  id,
  workspace,
  model,
});
const http = new AgentHTTP(agent);
const binding = await http.server().listen({ host: "127.0.0.1", port: 5314 });
console.log(binding.url); // http://127.0.0.1:5314

// 关闭
await http.close();
await agent.dispose();
```

### 方式 2：挂载到你自己的 Hono server

`AgentHTTP.router()` 返回一个 `Hono` 子路由，可以直接挂载：

```ts
import { Hono } from "hono";
import { AgentHTTP } from "@downcity/city";

const app = new Hono();
const http = new AgentHTTP(agent);
app.route("/", http.router());
```

CORS / logger / 鉴权等中间件由你自行决定。`AgentHTTP` 不会附带任何中间件。

## 与 Downcity、RemoteAgent 的关系

- `downcity on` 创建一个 `City`，恢复全部 Agent，并分别启动一个 City HTTP 端口和一个 City RPC 端口。
- City HTTP 地址为 `http://127.0.0.1:5314/agents/<agent_id>`；City RPC 地址为 `rpc://127.0.0.1:15314/<agent_id>`。
- `RemoteAgent` 客户端可以连到 `AgentRPC.listen()` 暴露的 `rpc://` 地址，或 `AgentHTTP` 暴露的 HTTP 表面。
