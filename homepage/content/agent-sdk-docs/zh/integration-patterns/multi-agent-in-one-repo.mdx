# 一个仓库里多个 Agent

如果你在同一个项目目录里创建多个本地 SDK Agent，最重要的是：

- 给每个 agent 一个稳定且不同的 `id`

例如：

```ts
const planner = new Agent({ id: "planner" });
planner.enter(new Workspace({ id: "planner-project", path: repo_path }));

const reviewer = new Agent({ id: "reviewer" });
reviewer.enter(new Workspace({ id: "reviewer-project", path: repo_path }));
```

每个 Agent 必须使用独立的 Workspace 实例。两个 Workspace 可以指向同一物理目录；Store 会按 `agent_id` 分区，因此 Session 不会混在一起。如果两个 Agent 都需要命令能力，也应分别创建和传入 Shell 实例。

如果你做的是“同一仓库里多个不同角色的 agent”，这会非常有用。
