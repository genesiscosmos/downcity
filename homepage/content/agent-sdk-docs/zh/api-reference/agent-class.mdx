# Agent 类

`Agent` 是本地 SDK 中可跨项目复用的执行主体，拥有稳定 ID、可见名称、能力描述、指令、模型、自定义 Tool 和 Session 集合。它不持有 Plugin，也不永久绑定 Workspace。

## 公开 API

- `new Agent(options)`
- `agent.id`
- `agent.name`
- `agent.description`
- `agent.sessions.create({ workspace })`
- `agent.set_instruction(input)`
- `agent.get_instructions()`
- `agent.get_logger()`
- `agent.dispose()`

Session 由 Agent 创建，并在创建时显式选择 Workspace：

```ts
const session = await agent.sessions.create({ workspace });
```

## 构造参数

- `id`：稳定 Agent 身份和私有数据分区键。
- `name`：可选的用户可见名称；省略时使用 `id`。
- `description`：可选的一句话能力简介，供展示与 Group 语义调度使用。
- `tools`：该 Agent 创建的 Session 可使用的自定义 Tool。
- `instruction`：Agent 级静态基础指令。
- `model`：默认 `ModelClient`，本地 Session 可以覆盖。
- `session_class`：可选的本地自定义 Session 类。

构造参数中没有 `workspace`。宿主独立创建 Workspace，并在 Agent 需要进入项目执行时调用
`agent.sessions.create({ workspace })`。

一个 Agent 可以在多个 Workspace 中创建 Session。Workspace 只在创建 Session 时传入，不会成为
Agent 的公开对象。Plugin 由 City 提供，City 中全部 Plugin 自动对全部 Agent 可用；执行时从
`city.enter_workspace()` 返回的 `entry.plugins` 调用。`agent.dispose()` 会释放 Session 与当前
City 绑定；网络 transport 仍由宿主负责关闭。
