# AgentRPC

`AgentRPC` 是本地 Agent 的 TCP RPC 传输层，让其他进程或服务可以通过主机和端口访问 agent 的会话，无需走 HTTP。

需要额外安装 `@downcity/city`：

```bash
pnpm add @downcity/city
```

## 最小示例

```ts
import { AgentRPC } from "@downcity/city";
import { Agent, Workspace } from "@downcity/agent";

const agent = new Agent({
  id: "demo",
  workspace: new Workspace({ path: process.cwd() }),
  model,
});
const rpc = new AgentRPC(agent);

const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
```

## 构造参数

```ts
new AgentRPC(agent: Agent)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `agent` | `Agent` | 已构造好的本地 Agent 实例 |

## 方法

### `listen(options?)`

启动 RPC 监听。

```ts
const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
// 返回 AgentRpcBinding，包含 TCP 连接端点信息
```

### `close()`

停止 RPC 服务并释放资源。

```ts
await rpc.close();
```

另见：[AgentHTTP](/zh/agent-sdk-docs/api-reference/agent-http) HTTP 传输层。
