# AgentRPC

`AgentRPC` 是一个本地 `AgentWorkspace` 的 TCP RPC 传输层，让其他进程通过主机和端口访问该 Workspace 的会话，无需走 HTTP。

需要额外安装 `@downcity/city`：

```bash
pnpm add @downcity/city
```

## 最小示例

```ts
import { AgentRPC } from "@downcity/agent/city";
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";

const agent = new Agent({
  id: "demo",
  model,
});
const agent_workspace = agent.enter(new Workspace({ id: "project", path: process.cwd() }));
const rpc = new AgentRPC(agent_workspace);

const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
```

## 构造参数

```ts
new AgentRPC(agent_workspace: AgentWorkspace)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `agent_workspace` | `AgentWorkspace` | 需要暴露的本地 Agent 执行作用域 |

## 方法

### `listen(options?)`

启动 RPC 监听。

```ts
const binding = await rpc.listen({ host: "127.0.0.1", port: 15314 });
// 返回 AgentRpcBinding，包含 TCP 连接端点信息
```

### `close()`

停止 RPC 服务并释放资源。

```ts
await rpc.close();
```

另见：[AgentHTTP](/zh/agent-sdk-docs/api-reference/agent-http) HTTP 传输层。
