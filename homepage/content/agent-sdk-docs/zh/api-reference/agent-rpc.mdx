# City RPC

RPC 属于 `City`，不属于单个 `Agent`。使用 `city.rpc()` 在一个 NDJSON-over-TCP 监听器中暴露当前 City
中的全部 Agent。

```ts
const rpc = await city.rpc({ host: "127.0.0.1", port: 15314 });
console.log(rpc.binding()?.url);
await city.close();
```

Remote 客户端使用 `rpc://host:port/<agent_id>/<workspace_id>`。完整示例参见 [City transport](/zh/city-sdk-docs/zh/packages/city/transport)。
