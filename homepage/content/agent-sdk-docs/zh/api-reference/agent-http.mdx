# AgentHTTP

`AgentHTTP` 是一个本地 `AgentWorkspace` 的 HTTP 传输层，暴露 RemoteAgent 所需的 Session API 与审批端点。

需要额外安装 `@downcity/agent`：

```bash
pnpm add @downcity/agent
```

## 最小示例

```ts
import { AgentHTTP } from "@downcity/agent/city";
import { Agent } from "@downcity/agent";
import { Workspace } from "@downcity/workspace";

const agent = new Agent({
  id: "demo",
  model,
});
const workspace = new Workspace({ id: "project", path: process.cwd() });
const http = new AgentHTTP(agent, workspace);

const binding = await http.server().listen({ host: "127.0.0.1", port: 5314 });
// HTTP 服务监听在 http://127.0.0.1:5314
```

## 构造参数

```ts
new AgentHTTP(agent: Agent, workspace: Workspace)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `agent_workspace` | `AgentWorkspace` | 需要暴露的 Agent 与 Workspace |

## 方法

### `listen(options)`

启动 HTTP 服务。

```ts
const binding = await http.server().listen({
  host: "127.0.0.1",
  port: 5314,
});
```

### `close()`

停止 HTTP 服务。

```ts
await http.close();
```
