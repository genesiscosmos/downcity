# SDK HTTP 端点

这组 SDK 路由不属于 `Agent` 自身。

它们由 [`@downcity/server`](/zh/agent-sdk-docs/local-agent/http-and-rpc) 提供的 `AgentHTTP` 暴露，可作为独立 HTTP server 启动，也可挂到 Downcity gateway 等任何 Hono server 上。

当前核心包括：

- `GET /api/sdk/sessions`
- `POST /api/sdk/sessions`
- `GET /api/sdk/sessions/:session_id`
- `POST /api/sdk/sessions/:session_id/prompt`
- `GET /api/sdk/sessions/:session_id/events`
- `GET /api/sdk/sessions/:session_id/messages`
- `GET /api/sdk/sessions/:session_id/system`
- `GET /api/sdk/sessions/:session_id/approvals`
- `GET` / `POST /api/sdk/sessions/:session_id/approval-mode`
- `POST /api/sdk/sessions/:session_id/approval`
- `POST /api/sdk/sessions/:session_id/fork`
- `POST /api/sdk/sessions/:session_id/archive`
- `GET` / `DELETE /api/sdk/archived-sessions`
- `POST /api/plugins/action`

## 设计目标

这套接口不是一个通用“大而全 API”，而是一组尽量小、围绕 session 使用面展开的 SDK 路由。

它的重点不是扩展成复杂平台 API，而是保证本地 `Agent` 和 `RemoteAgent` 之间的能力面对齐。

## 典型使用方式

```bash
downcity agent start
```
