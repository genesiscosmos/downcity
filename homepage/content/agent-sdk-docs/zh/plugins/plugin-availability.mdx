# Plugin Availability

Plugin 当前需要区分两个事实：

- 是否已经注册到 City，并因此投影到全部 Agent。
- 当前 Agent/Workspace 环境是否满足 Plugin 自己的 `availability()` 检查。

```ts
const plugins = city.plugins.scope({ agent_id: agent.id, workspace_id: workspace.id });
plugins.has("skill");
plugins.status("skill");
await plugins.availability("skill");
```

Plugin 加入 City 且 `start` 尚未完成时为 `initializing`；启动成功后为 `ready`；启动失败时为
`error`。普通 Action 的业务失败不会改变整个 Plugin 的状态。

`availability()` 只回答当前 Context 中是否真正可用，例如 Provider、依赖、模型或凭据是否就绪。
它不控制 Agent 是否绑定 Plugin；City 中的全部 Plugin 始终对全部 Agent 可见。
