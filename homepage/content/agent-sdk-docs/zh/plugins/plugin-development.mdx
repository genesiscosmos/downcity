# Plugin 开发指南

Plugin 作者 API 位于 `@downcity/city/plugin`。一个 `CityPluginModule` 同时定义 main 生命周期和
Profile 执行实例 factory；Agent 包不再导出 Plugin 作者协议。

## 执行实例

```ts
import { BasePlugin, create_action } from "@downcity/city/plugin";
import { z } from "zod";

class ExamplePlugin extends BasePlugin {
  readonly name = "example";
  readonly title = "Example";
  readonly description = "An example Plugin.";

  constructor(private readonly client: ExampleClient) {
    super();
  }

  readonly actions = {
    status: create_action({
      description: "Return the current scope.",
      input_schema: { zod: z.object({}) },
      execute: async ({ context, execution }) => ({
        success: true,
        data: {
          agent_id: context.agent.id,
          workspace_id: context.workspace.id,
          session_id: context.session?.id ?? null,
          call_id: execution.call_id,
        },
      }),
    }),
  };
}
```

Workspace 用户文件使用 `context.workspace.files`；Plugin 私有状态使用 `context.storage.files`。
`context.session` 与 `context.agent.sessions` 是可直接调用的受限句柄，不需要只依赖 ID 回查对象。

## 统一 City module

```ts
import { define_city_plugin } from "@downcity/city/plugin";

export default define_city_plugin({
  activate(context) {
    context.plugin.action({
      id: "about",
      run: () => ({ name: "example" }),
    });
  },
  create({ profile }) {
    return new ExamplePlugin(new ExampleClient(profile.config));
  },
});
```

SDK 宿主把该 module 放入 `CityPluginRegistration`，先交给 City，再按 ID 绑定 Agent：

```ts
const registration = {
  id: "example",
  title: "Example",
  description: "An example Plugin.",
  readme: "/absolute/path/README.md",
  has_config: false,
  has_sidebar: false,
  has_mainview: false,
  module: example_module,
};

const city = new City({ plugins: [registration], workspaces: [workspace] });
city.agents.add(agent, { plugins: [{ plugin_id: "example" }] });
```

## 生命周期

`start/stop` 属于 City 的 `(plugin_id, profile_id)` 共享实例；`bind/unbind` 属于
Agent/Workspace scope。Profile 级 client、连接与缓存放在 `start/stop`，scheduler、路由或
scope worker 放在 `bind/unbind`。所有异步 Action 都应传递 `execution.abort_signal`。

## 可安装包

```text
example-plugin/
├── plugin.json
├── package.json
├── README.md
├── dist/main.js
└── dist/renderer.js
```

```json
{
  "schema_version": 1,
  "id": "example",
  "version": "1.0.0",
  "description": "A small example Plugin.",
  "readme": "./README.md",
  "main": "./dist/main.js",
  "renderer": {
    "entry": "./dist/renderer.js",
    "sidebar": true,
    "mainview": true,
    "config": false
  }
}
```

`main` 默认导出 `CityPluginModule`，不再存在独立 `agent` 入口。Renderer 只通过宿主 action
gateway 通信，不能直接访问 Node、Electron、Agent 或 Profile 文件。

## 测试重点

- 相同 Profile 多 Agent 只创建和 `start` 一次。
- 每个 Agent/Workspace scope 恰好 `bind/unbind` 一次。
- 最后一个 execution lease 释放后才 `stop`。
- main 并发调用只 `activate` 一次，关闭时完整 `deactivate`。
- Action 输入、JSON 结果和取消信号正确。
