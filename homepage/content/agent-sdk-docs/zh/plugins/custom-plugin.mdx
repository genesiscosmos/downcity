# 自定义 Plugin

自定义 Plugin 的公开协议来自 `@downcity/plugin`。Agent 不接收 Plugin 实例，也不暴露 Plugin
Registry；City 先登记 module，再按 `plugin_id`/Profile 绑定 Agent。

```ts
import {
  BasePlugin,
  define_city_plugin,
  type PluginActions,
} from "@downcity/plugin";

class NotesPlugin extends BasePlugin {
  readonly name = "notes";
  readonly title = "Notes Helper";
  readonly description = "Adds note-related actions.";

  readonly actions: PluginActions = {
    status: {
      execute: async ({ context }) => ({
        success: true,
        data: {
          workspace_path: context.workspace.path,
          storage_path: context.storage.path,
          session_id: context.session?.id ?? null,
        },
      }),
    },
  };
}

const notes_module = define_city_plugin({
  activate() {},
  create: () => new NotesPlugin(),
});

const registration = {
  id: "notes",
  title: "Notes Helper",
  description: "Adds note-related actions.",
  readme: "/absolute/path/README.md",
  has_config: false,
  has_sidebar: false,
  has_mainview: false,
  module: notes_module,
};

const city = new City({ plugins: [registration], workspaces: [workspace] });
city.agents.add(agent, { plugins: [{ plugin_id: "notes" }] });
```

只实现领域真正需要的 Action、Hook、Resolve、System、Availability、HTTP 或 Lifecycle。
共享 Profile 资源使用 `start/stop`，Agent/Workspace 作用域资源使用 `bind/unbind`；不要把长期资源
偷偷放进 Hook。

完整的 module、manifest、Context 与测试说明见
[Plugin 开发指南](/zh/agent-sdk-docs/plugins/plugin-development)。
