---
Power 可以实现：

```ts
system(context) {
  return "power-level system text";
}
```

## 它的作用

`power.system()` 表达的是：

- 这个 Power 希望向 agent 运行时补充一段 system 文本

典型用途：

- 注入 provider 使用规则
- 注入某类能力的操作约束
- 告诉 agent 当前有哪些外部能力已经准备好

在完整 runtime 的系统提示词收集链路里，Power system 是正式注入的一层。

当前 runtime 会：

- 遍历全部内建 Power
- 只对启用的 Power 取 `system()`
- 单个 Power 失败时 fail-open，不阻断主链路

## 什么时候适合写 Power.system

这些内容更适合放到 Power.system：

- 某个 Power 的使用方法论
- 当前 provider 的工作约束
- 已安装能力的统一说明

## 哪些内建 Power 典型用到了它

- `skill`
- `web`
- `sound`

它们都非常适合注入“能力说明型 system 文本”。
