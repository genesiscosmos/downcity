# Toggle

Toggle 用于工具栏里的“按下态”操作，例如列表/网格视图、加粗、固定面板。它不是布尔设置；设置页的开关请使用 `Switch`。

切换单个状态或一组选项。

<ComponentDemo component_id="toggle" />

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@downcity/ui";

export function Example() {
  return (
    <ToggleGroup defaultValue={["grid"]}>
      <ToggleGroupItem value="list">List</ToggleGroupItem>
      <ToggleGroupItem value="grid">Grid</ToggleGroupItem>
    </ToggleGroup>
  );
}
```

`ToggleGroupItem` 必须放在 `ToggleGroup` 中。
