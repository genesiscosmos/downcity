# ScrollArea

提供与宿主样式一致的独立滚动区域。

## Preview

<ComponentDemo component_id="scroll-area" />

## Usage

```tsx
import { ScrollArea, ScrollAreaContent, ScrollAreaViewport } from "@downcity/ui";

export function Example() {
  return <ScrollArea className="h-48"><ScrollAreaViewport><ScrollAreaContent>Content</ScrollAreaContent></ScrollAreaViewport></ScrollArea>;
}
```
