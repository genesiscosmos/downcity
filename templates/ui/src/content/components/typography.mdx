# Typography

提供完整的文章渲染层，包括六级标题、正文层级、引用、Annotation、脚注、任务列表、嵌套列表、定义列表和行内代码。

<ComponentDemo component_id="typography" />

## Usage

```tsx
import { Annotation, Blockquote, H2, Paragraph } from "@downcity/ui";

export function Content() {
  return (
    <>
      <H2>Project overview</H2>
      <Paragraph>Stable semantic hierarchy for product content.</Paragraph>
      <Blockquote>Structure should remain predictable.</Blockquote>
      <Annotation title="Note">ThemeContainer supplies the complete visual context.</Annotation>
    </>
  );
}
```
