# Toaster

承载非阻断式全局反馈。

## Preview

<ComponentDemo component_id="toaster" />

## Usage

```tsx
import { ThemeContainer, Toaster } from "@downcity/ui";
import { toast } from "sonner";

export function App() {
  return <ThemeContainer variant="neutral" mode="light"><button onClick={() => toast.success("Saved")}>Save</button><Toaster /></ThemeContainer>;
}
```

每个应用根节点只挂载一个 Toaster；它与其他组件一样继承 ThemeContainer，不接收独立主题参数。调用 `toast` 时宿主需要安装 `sonner`。
