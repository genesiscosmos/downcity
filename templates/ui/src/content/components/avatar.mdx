# Avatar

展示用户、项目或实体的紧凑身份标识；始终提供 Fallback。

## Preview

<ComponentDemo component_id="avatar" />

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@downcity/ui";

export function Example() {
  return <Avatar><AvatarImage src="https://example.com/avatar.png" alt="Avery Stone" /><AvatarFallback>AS</AvatarFallback></Avatar>;
}
```
