# Button

触发主要、次要或危险操作。

## Preview

<ComponentDemo component_id="button" />

## Usage

```tsx
import { Button, ThemeContainer } from "@downcity/ui";

export function Example() {
  return (
    <ThemeContainer variant="blue" mode="dark">
      <Button variant="primary"><PlusIcon />Create<ArrowRightIcon /></Button>
    </ThemeContainer>
  );
}
```

## API

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `primary \| default \| outline \| secondary \| ghost \| destructive \| link` | `default` |
| `size` | `default \| xs \| sm \| lg \| icon-*` | `default` |
| `render` | `ReactElement` | — |

异步状态通过 `Spinner`、`disabled` 与 Button 组合。

`default` 与 `ghost` 是 Vibecape 风格的轻量文本操作；`primary` 用于每个区域的主要动作。所有 variant 都消费 `ThemeContainer` 提供的主题 token，组件调用不需要传入主题 class。仅传入一个 SVG 图标时，Button 会自动采用图标按钮尺寸。
